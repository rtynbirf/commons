# ADR-0002: MCP как универсальный синапс

Статус: принято · Дата: 2026-11-01

## Контекст

Органам нужен единый способ выставлять инструменты телу. Варианты: собственный RPC, OpenAPI-прокси, Model Context Protocol (MCP).

## Решение

MCP — стандарт синапсов COMMONS. Каждый орган объявляется в `synapse/mcp-manifest.yaml` как MCP-сервер (stdio или http); тело не вызывает органы напрямую. Орган без записи в манифесте для тела не существует (событие `veto` в крови).

## Последствия

- (+) MCP — де-факто стандарт 2026 года для инструментария агентов: экосистема серверов и клиентов уже существует, инструменты органов переиспользуются вне организма;
- (+) органы не обязаны знать друг о друге — контракт управляется декларативно манифестом;
- (+) замена органа прозрачна для ствола мозга (SPEC-0001, гарантия G2);
- (−) дополнительный слой транспорта — принимаем ради единообразия и трассируемости;
- (−) органы без готового MCP-сервера требуют тонкого адаптера (режим `adapter`).
