# Отчёт волны №22 — обратимость честным языком + бюджет после шага (W-0024 + W-0029)

Дата: 2026-11-03 · База: `dad6dbb` (0.40.0, стык тактов тождества — после неё) ·
Директива Человека: «одно другое не исключает» — две хотёлки одной волны:
зерно пакета «Human Membrane» (FR-05/FR-06, ADR-002 — Saga) и зерно коллег
(F-07 внешнего аудита 2026-11-03), прогнанные замером на живом коде.

## Что служено

### W-0029 — бюджет останавливает после последнего шага (SPEC-0001 v0.4.0 G3)

Зерно коллег F-07: проверка бюджета жила только ПЕРЕД шагом — перерасход
последним шагом давал `run() = True` без halt: трейс проходил с превышенным
бюджетом, и проход выглядел успехом. Честная граница перевернута:

- бюджет проверяется **до шага и после шага** — исчерпание после шага пишет
  `halt` («бюджет исчерпан: …», `at_step` = шаг, перерасход оплативший) и
  возвращает `False`; трейс полон (G1), перерасход назван, не спрятан;
- halt падает сразу после шага, исчерпавшего бюджет, — следующий шаг даже
  не планируется (раньше halt ждал проверки перед следующим шагом);
- старые приёмки перевернулись честно: `test_alert_once_at_threshold`
  (4×30 при лимите 100 — было `run()=True` с totals=120; стало halt),
  `test_alert_and_halt_ordering` (halt `at_step` 2→1), `test_reconstruct_halted_session`
  (halt `at_step` 1→0 — бюджет исчерпан первым же вызовом).

### W-0024 — обратимость честным языком (SPEC-0001 v0.4.0 пп.5–6, SPEC-0003 v0.13.0 п.16)

Зерно пакета (Saga, FR-05/FR-06): у дома не было понятия обратимости действия.
Обещание универсальной отмены отвергнуто (конституция пакета сама его
запрещает — мы запрещаем тоже). Вжито по духу дома:

- **класс заявляется ДО факта**: `Step.reversibility` из словаря пакета
  (`reversible` / `compensatable` / `partially_reversible` / `irreversible` /
  `unknown`; словарь один — `blood.envelope.REVERSIBILITY_CLASSES`, копий нет);
  план несёт заявку, шлюз переносит её в акт — заявка путешествует с
  действием, в том числе к замене органа. Не заявлено — поля нет: старые
  планы и пролитая кровь валидны навсегда (аддитивно, A02);
- **опечатка не значит молча «unknown»**: класс не из словаря — дефект плана,
  halt до факта (fail-closed, ADR-0014); прямой вызов шлюза с чужим классом —
  `veto` + `SynapseVeto` до invoke;
- **необратимое без одобрения не исполняется** (FR-06): `veto` до факта + halt
  (G1), акта в крови нет, орган не вызван. «Спрашивать» для ствола —
  остановиться и назвать, чего не хватает; решение — за Человеком (PID 1).
  Одобрение — `Step.approval`, строка-заявка («кто одобрил»), доверие
  unverified по природе — честно;
- **компенсация — новая операция, не редактирование прошлого** (`brainstem/compensator.py`):
  кровь append-only — отмена ничего не вычёркивает; отдельный трейс с
  `causation_id` = id акта (честное происхождение) и идемпотентным ключом
  `compensate:{act_id}` (A01: повторная компенсация не создаёт вторую строку
  акта — проверено живьём, строка одна при двух компенсациях);
- **проверка состояния после обязательна**: без критерия приёмки (общая
  грамматика W-0027 — `measure_criterion`) компенсация не запускается:
  «результат есть» ≠ «отменено» (ValueError до факта, кровь не тронута);
- **вердикты — словарь пакета**: `COMPENSATED` (состояние после принято
  критерием) / `COMPENSATION_PARTIAL` — не PASS (`satisfied=false`, трейс
  закрыт halt; частичность заявляет сам орган в результате — дом не
  догадывается) / `NOT_REVERSIBLE` (класс акта irreversible или компенсатор
  не объявлен манифестом — попытки не было, A17);
- **компенсатор объявляется манифестом** — `compensators: {инструмент:
  инструмент отмены}` (данные, не код — G2); кривое объявление — шлюз не
  стартует; у органа без компенсатора отмена не выдумывается;
- **дневник говорит по классу** (п.12/п.16): необратимое — «не отменяется»,
  заявленный класс — «компенсацией», незаявленный — «класс обратимости не
  заявлен — отмена не обещается», чужой — назван, не спрятан; протухшая
  фраза «компенсатор не построен (W-0024)» выметена (W-0024 СЛУЖЕНО).

## Границы, названные честно

- класс обратимости — заявка автора действия (unverified по природе): дом
  не проверяет мир сам, он читает отчёт органа о состоянии после (критерий);
- компенсация работает с кровью, доступной журналу (сессия или присоединённый
  файл) — чужая пролитая кровь валидна навсегда, но компенсируется только там,
  где жив журнал;
- частичность заявляет орган (`"compensation": "partial"`) — дом не лезет в
  чужой орган за синапсами мерить мир сам;
- одобрение — строка-заявка в крови, доверие unverified: честность одобрений
  держится на вторых свидетелях (кровь, параллельная линия, CI), не на совести
  отдельного исполнителя.
