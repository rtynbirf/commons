# Спайк S2: агентный цикл — langchain против собственного

Статус: замер проведён (2026-11-01, фейковая модель — измеряется каркас, не LLM) ·
Ограничение: ≤3 дня · Родитель: `docs/spikes.md` (S2) · Связь: SPEC-0001, ADR-0004

## Метод

`measure.py` гоняет одну и ту же задачу («сделай пустое дело») через два каркаса:

- **langchain 1.x** (`create_agent`): фейковая модель-рекордер записывает, что уходит провайдеру,
  включая схемы инструментов через `bind_tools` (реальный трафик);
- **COMMONS ствол мозга** (SPEC-0001): фиксируется, что уходит органу — план (intent) и payload.

≈Токены = символы // 4 (маркировка приближённости; на живом токенизаторе пропорция сохранится).

## Замер (2026-11-01, langchain 1.4.7)

| путь | вызовов модели | сообщений | scaffolding, симв | ≈ токенов |
| --- | --- | --- | --- | --- |
| langchain 1.x (без инструментов) | 1 | 1 | 18 | 4 |
| langchain 1.x (1 инструмент) | 1 | 1 | 238 | 59 |
| COMMONS ствол мозга (SPEC-0001) | 1 | 1 | 36 | 9 |

## Чтение результата

1. **Без инструментов каркасы равны** (4 ≈ 9 токенов): langchain не добавляет накладных
   расходов на «пустом» агенте — миф о «тяжёлом» каркасе без инструментов не подтвердился.
2. **Инструменты едут в промпте**: +55 ≈токенов на один инструмент. На 20 инструментах —
   ~1 100 токенов на каждый вызов модели, умножается на каждое обращение.
3. **В COMMONS схемы инструментов — статика манифеста**, а не трафик: манифест читает шлюз,
   промпт не раздувается. Орган получает только намерение и payload.
4. **Трассируемость**: наш путь пишет каждый переход в кровь (конверты SPEC-0003) — реконструкция
   трейса бесплатна; у langgraph состояние не является append-only журналом с ценой.

## Вердикт (критерий выхода docs/spikes.md S2)

Свой цикл не хуже по токенам и лучше по трассируемости — **SPEC-0001 остаётся в силе**;
пересмотра не требует. langchain — законный орган-`nerves_alt` для внешних интеграций
(MIT, реестр), но не замена стволу мозга. Финальное подтверждение на живом LLM —
при подключении метаболизма на постоянной машине (замер каркаса от модели не зависит).

## Воспроизведение

```bash
pip install langchain
python3 spikes/s2-cycle/measure.py
```

Без langchain харнесс печатает `NO_LANGCHAIN` (код 2) — цифры не выдумываются.
