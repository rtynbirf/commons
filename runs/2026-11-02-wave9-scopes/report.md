# Волна №9: скоупы полномочий (SPEC-0002 v0.5.0)

Дата: 2026-11-02 · Версия тела: 0.23.0 · Прогон: `python runs/2026-11-02-wave9-scopes/run.py` (из корня репо)

## Постановка

Волна №7 («исполнение полномочий») честно записала свою слепую зону: страж знает ярлыки
(`read-write`, `any`), но не знает путей и портов — орган получает честно широкий ярлык и пишет
куда угодно. Спека (SPEC-0002 v0.4.0 п.8) прямо назвала преемника: «скоуп каталогов (downloads-dir)
и портов — бэклог v0.5». Волна №9 закрывает эту дыру по ритуалу «спека до кода»: сначала грамматика
в спеке, потом красный прогон на щели, потом код, потом переворот прогона.

## Что реализовано

- **fs-скоуп** `{mode: none|read-only|read-write, paths: ["/abs/dir", ...]}`: события `open` и мутации
  (`os.remove/rename/mkdir/rmdir/chmod/chown`) разрешены только внутри заявленных корней; сравнение по
  `realpath` — симлинк-побег закрыт; исключение рантайма Python живо и при скоупе (орган не умирает от
  собственного скоупа); `os.rename` требует оба конца внутри корней; `mode` управляет, `paths` работают
  только для read-only/read-write.
- **network-скоуп** `{hosts: [...], ports: [...]}`: порт `socket.connect`/`socket.bind` обязан быть
  заявленным (точное совпадение: порт 0 и эфемерные диапазоны не заявляемы); `ports` без `hosts` —
  не грамматика; `getaddrinfo` порта не несёт — проверяется только хост.
- **плейсхолдеры п.6 в authority**: `${VAR}` в путях скоупов разрешается до нормализации грамматики;
  незаданная переменная — «орган не развёрнут» (адаптера нет, healthcheck ложь), шлюз стартует,
  соседи живы. Endpoint/command-семантика не тронута.
- **манифест дома v0.4.0**: ollama — `{hosts: [localhost], ports: [11434]}`, llama.cpp —
  `{hosts: [localhost], ports: [8080]}`, browser-use — `fs: {mode: read-write, paths: ["${DOWNLOADS_DIR}"]}`;
  README органа переписан (ярлыки `allowlist`/`downloads-dir` из 0.13.0 были декоративными).

## Слепые зоны (честно)

- Живой хост: настоящий browser-use с браузером, настоящий ollama:11434 — на машине человека (PID 1).
- IPv6-литералы и зоны в hosts: точное совпадение строк — заявляемо, но не покрыто прогоном.
- TOCTOU-гонка (символическая ссылка, подменённая между realpath и open) — уровень ОС; страж закрывает
  ту щель, которая в его власти: сам вызов.
- Thread-модель стража — та же, что у волны №7 (contextvar + audit hook на процесс).
