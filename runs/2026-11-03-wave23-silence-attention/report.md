## Что служено

### W-0032 — правило тишины: необратимое без ответа отменяется по умолчанию (SPEC-0004 v0.2.0 п.7, ADR-0015)

У тишины теперь есть записанное окно и по-записанное поведение по умолчанию.
Правило наружу уже работало (донорский триггер тишины —
`runs/2026-11-03-wave17-membrane-blood/donors-sweep.md`); стало общим — и
внутрь дома (`brainstem/approval.py`):

- **запрос — событие крови** `approval.request` с ЗАЯВЛЕННЫМ окном
  (`window_seconds`), приоритетом внимания и вычисленным `expires_at`;
  запроса без окна не существует — окно ≤ 0 и чужой приоритет роняются ДО
  записи (fail-closed, ADR-0014), конверта нет — события нет;
- **одобрение — `approval.grant`** с `causation_id` запроса (честное
  происхождение, SPEC-0003 п.10) и `who` (строка-заявка, unverified —
  W-0024); ключ `approval.grant:{request_id}` — повтор не дублирует (A01);
- **ответ по-записанному** (`answer`): одобрение с временем факта до окна —
  `granted`; окно истекло без одобрения — правило само пишет `veto`
  (source `pid1`, причина «правило тишины…», ключ
  `approval.silence:{request_id}`, A01) — **по умолчанию «нет»**,
  необратимое не исполнено (A17); до окна — `waiting`, ничего не пишет;
- **опоздавшее одобрение** остаётся в крови вестью (append-only) —
  необратимое не оживляет; в метриках названо отдельным счётом
  (`late_approvals`), не спрятано и не перепутано с решениями;
- **ожидание не останавливает дом** (инвариант 32): тишина — пауза внутри
  МЫ; остановлено только само необратимое действие, работа идёт дальше —
  в живом прогоне пять трейсов идут один за другим, никто никого не ждал.

### W-0025 — бюджет внимания человека (SPEC-0004 v0.2.0 п.8, SPEC-0003 v0.14.0 п.17)

Внимание Человека — ресурс организма, счёт — только по заявленной крови
(`brainstem/attention.py`, человеческий контур поверх — ADR-0013):

- **цена внимания**: `cost.attention` — необязательное целое ≥ 0; отсутствие
  = не заявлено (A02), ноль не пишется — старый стиль крови жив; `totals`
  суммируют; дневник показывает («внимание Человека 1»);
- **словарь приоритетов один** — `ATTENTION_PRIORITIES`: P0 остановка перед
  риском/необратимостью (спрашивает всегда — у риска нет безопасного
  default), P1 срочное существенное (спрашивает без безопасного default),
  P2 дневная сводка, P3 тихая запись (не прерывают);
- **косметические вопросы не задаются**: `should_ask` — вопрос с безопасным
  default, который можно изменить позже, не задаётся (запись вместо вопроса);
  ствол вживил цену: veto на необратимое без одобрения — это P0-вопрос,
  `cost.attention=1` (остановка и вопрос Человеку — заявленная цена);
- **скрытой поведенческой телеметрии нет и не будет**: `metrics()` — чистая
  read-проекция заданной крови (ни файлов, ни сети, ни скрытого состояния);
  неизмеримое = UNKNOWN (None), не ноль; «меньше вопросов не значит лучше,
  если растут опасные действия» — метрики показывают вопросы и необратимые
  действия рядом (`dangerous_actions`), оборотную сторону не прячут.

## Живой прогон (этот каталог)

Кровь живая: `blood.jsonl` — 13 конвертов, гэпов 0, chained, hashed,
опечатана якорем (`blood/anchors.jsonl`, name `wave23-silence-attention`).
Пробы живьём:

1. необратимое без одобрения — veto до факта, `cost.attention=1`, орган не
   вызван, состояние пусто;
2. `approval.request` (P0, окно 1 ч) → ожидание (`waiting`) →
   `approval.grant` → `granted`, causation_id честный;
3. повторный план с одобрением — необратимое исполнено, акт несёт заявленный
   класс;
4. запрос P1 с окном 1 с, живой сон 1.2 с — veto от правила тишины
   («по умолчанию нет»), повторное решение — та же строка (A01);
5. опоздавшее одобрение — весть в крови, решение правила стоит, `pending`
   пуст;
6. метрики внимания: вопросов 2 (прерываний 2), granted 1, отменено тишиной
   1, опоздавших одобрений 1, ожидание 1.201 с (живое), опасных действий 1.

Метод повторения: `python3 runs/2026-11-03-wave23-silence-attention/run.py`.

Честные границы: одобрение в живом прогоне — заявка Человека в кадре прогона
(unverified по природе — W-0024), не подпись; окно — заявка просящего
(fail-closed ловит отсутствие, не глупость); якорь живёт в доме — полная
заверка против хозяина файла — за границей репо (названо в SPEC-0003 п.15).
