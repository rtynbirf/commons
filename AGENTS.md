# AGENTS.md — инструкции для AI-агентов

COMMONS ведётся людьми и агентами. Агенты — полноправные клетки организма; на них распространяются те же три закона.

## Контекст проекта (порядок чтения)

1. `docs/manifesto.md` — аксиомы целого и части.
2. `specs/` — геном: контракты ствола мозга, синапсов, крови.
3. `organs/registry.yaml` — состав органов и режимы.
4. `ROADMAP.md` — текущая веха и критерии готовности.

## Правила работы

1. **Спеки — источник истины.** Изменение поведения начинается с правки `specs/`, код следует за спекой.
2. **Органы не форкать** (ADR-0001): подключение — через `synapse/mcp-manifest.yaml`, улучшения отправляются в upstream.
3. **Каждый вызов органа несёт конверт крови** (SPEC-0003) с заполненной `cost`. Событие без цены недействительно.
4. **Новые органы** — только через issue-шаблон «Заявка органа» и лицензионный барьер; AGPL/fair-code — только режим `external`.
5. **Секреты не коммитятся никогда**: токены, ключи, `.env`. Шаблон окружения — `.env.example`.
6. Коммиты — Conventional Commits; для органов: `organ: <repo> подключён в режиме <mode>`.
7. Архитектурное решение — сначала ADR в `docs/adr/` (Статус / Контекст / Решение / Последствия), потом реализация.

## Проверки перед PR

- YAML и JSON валидны (это гоняет CI: `.github/workflows/ci.yml`);
- в каждом изменённом файле `specs/*.md` присутствует строка «Статус:»;
- `organs/registry.yaml` обновлён, если изменился состав органов;
- `THIRD_PARTY_NOTICES.md` обновлён, если добавлен чужой компонент;
- при архитектурном решении добавлен ADR.

## Запрещено агентам

- Обход синапсов: любые прямые вызовы органов мимо MCP-шлюза.
- Форки органов без ADR-обоснования.
- Выдуманные данные: метрики лицензий и звёзд берутся из живого API или помечаются как «предварительно».
