# AGENTS.md — инструкции для AI-агентов

COMMONS ведётся людьми и агентами. Агенты — полноправные клетки организма; на них распространяются те же три закона.

## Контекст проекта (порядок чтения)

1. `llms.txt` — карта репозитория для агент-клиентов.
2. `docs/manifesto.md` — аксиомы целого и части.
3. `specs/` — геном: контракты ствола мозга, синапсов, крови.
4. `organs/registry.yaml` — состав органов, режимы и верифицированные лицензии.
5. `docs/research-plan.md` → `docs/lenses.md` → `docs/spikes.md` — как кандидаты исследуются и принимаются.
6. `ROADMAP.md` — текущая веха и критерии готовности.

## Правила работы

1. **Спеки — источник истины.** Изменение поведения начинается с правки `specs/`, код следует за спекой.
2. **Органы не форкать** (ADR-0001): подключение — через `synapse/mcp-manifest.yaml`, улучшения отправляются в upstream.
3. **Каждый вызов органа несёт конверт крови** (SPEC-0003) с заполненной `cost`. Событие без цены недействительно.
4. **Новые органы** — только через issue-шаблон «Заявка органа» и лицензионный барьер; AGPL/fair-code — только режим `external`.
5. **Секреты не коммитятся никогда**: токены, ключи, `.env`. Шаблон окружения — `.env.example`.
6. Коммиты — Conventional Commits; для органов: `organ: <repo> подключён в режиме <mode>`.
7. Архитектурное решение — сначала ADR в `docs/adr/` (Статус / Контекст / Решение / Последствия), потом реализация. Шаблоны артефактов — в `docs/templates/`.
8. **Провенанс** ([`PROVENANCE.md`](PROVENANCE.md)): чужой код, тексты, логотипы и медиа не добавляются никогда — только имена, ссылки и верифицированные с датой факты.
9. **Лицензирование пофайловое** (REUSE 3.3, `REUSE.toml`): `reuse lint` в CI зелёный — обязательное условие; лицензии органов — только из живого API/файла LICENSE с датой.
10. **DCO**: коммит подписывается `git commit -s` (строка `Signed-off-by`, DCO 1.1).

## Проверки перед PR

- YAML и JSON валидны (это гоняет CI: `.github/workflows/ci.yml`);
- `reuse lint` проходит (REUSE 3.3, пофайловое лицензирование);
- в каждом изменённом файле `specs/*.md` присутствует строка «Статус:»;
- `organs/registry.yaml` обновлён, если изменился состав органов;
- `THIRD_PARTY_NOTICES.md` и `PROVENANCE.md` обновлены, если добавлен чужой компонент или изменилась лицензия;
- при архитектурном решении добавлен ADR;
- каждый коммит подписан `Signed-off-by` (DCO).

## Запрещено агентам

- Обход синапсов: любые прямые вызовы органов мимо MCP-шлюза.
- Форки органов без ADR-обоснования.
- Добавление чужого кода/текстов/медиа в любом виде — провенанс нарушается одним байтом.
- Выдуманные данные: метрики лицензий и звёзд берутся из живого API или помечаются как «предварительно».
