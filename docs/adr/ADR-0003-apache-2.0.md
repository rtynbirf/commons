# ADR-0003: Лицензия COMMONS — Apache-2.0

Статус: принято · Дата: 2026-11-01

## Контекст

Собственный код COMMONS (ствол мозга, синапсы, кровь, адаптеры) публикуется как открытый. Варианты: MIT, Apache-2.0, GPL-семейство.

## Решение

Apache-2.0 для всего собственного содержимого репозитория.

## Последствия

- (+) явный патентный грант — важно для организма, собирающего чужие компоненты;
- (+) совместимость с органами на MIT/BSD/Apache: зависимости-органы могут использоваться без конфликтов;
- (+) механизм NOTICE стыкуется с `THIRD_PARTY_NOTICES.md`;
- (−) текст длиннее и формальнее MIT — принимаем;
- (−) AGPL/GPL органы в тело не встраиваются. Это не следствие выбора Apache-2.0, а закон иммунитета: он работал бы при любой лицензии COMMONS.
