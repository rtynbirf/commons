# ADR-0014: Неизвестный тип крови — fail-closed при записи, файл помнит всё

Статус: принято · Дата: 2026-11-03
Спека: SPEC-0003 · Побудка: ревизия ревизора 2026-11-03 (§2.1 A17, Ф-0.1)

## Контекст

Матрица пакета «Human Membrane» (волна №15) требует приёмку A17:
неизвестный тип события сохраняется, но не исполняется. Кровь дома
отвечает противоположно: схема конверта (`blood/envelope.schema.json`)
сужает `type`.enum'ом, `Journal.append` валидирует до записи,
`from_jsonl` считает невалидное честным `skipped`. Ревизия признала
конфликт честным (оба правы по-своему) и потребовала ADR с границами
обоих режимов до PR-1.

## Решение

Два режима, граница между ними — граница «писать / читать»:

1. **Пишущий контур — fail-closed без исключений.** `Journal.append`
   и `make` не записывают конверт с неизвестным типом: кровь —
   исполняемая память, чужой тип в теле ломает гематологию, цепочку
   и всякого читателя. Новый тип входит в кровь только через приёмку:
   расширение enum'а схемы + тесты + спека (как входили organ.health,
   organ.replace). Пока тип не принят домом, он не кровь дома.
2. **Файл — append-only и всё помнит.** Уже пролитая строка с чужим
   типом из файла не удаляется никогда (SPEC-0003: переупорядочивание
   и удаление запрещены). Читатель (`from_jsonl`, `verify`) честно
   называет её `skipped` — сохранена в файле, не исполнена в памяти.
   Это и есть «сохраняется, но не исполняется» пакета: сохранение —
   обязанность файла, исполнение — прерогатива валидной крови.
3. **Знание о чужом типе — не потеря, а сигнал.** Рост `skipped` на
   живом файле — повод для разбора (алерт дома), а не повод ослаблять
   схему на лету. Схема крови меняется приёмкой, не рантаймом.

## Последствия

- Приёмка A17 закрыта честным разведением режимов: fail-closed при
  записи (дом), сохранение без исполнения при чтении (файл).
- `verify` и гематология остаются единственными судьями целостности;
  никто не «дорисовывает» чужому типу валидность задним числом.
- Ограничение: если будущий диспетчер (Ф-2, A24/A25) захочет
  транспортную очередь чужих конвертов — это отдельная спецификация с
  собственными приёмками; кровь дома остаётся fail-closed.
