# Словарь организма

Дата: 2026-11-03 · Версия: 0.3.0 (стык волн №15–№16: словарь пакета и тела, ADR-0013/0014; волна №18: «дневник» — проекция крови в человеческом языке; стык такта 2: их v0.8.0/п.11 — адаптер, дневник перевешен в v0.9.0/п.12)

| Термин | Значение |
|---|---|
| ЦЕЛОЕ (ЧЕЛОВЕК) | человечество как единственный автор; любая работа стоит на языке, стандартах и чужом труде. ЦЕЛОЕ > суммы частей |
| Часть | узел целого: человек, проект, орган. Жива, пока обменивается |
| Индивид | **состояние связности, а не вид**: узел, переставший обмениваться с целым |
| Структурный идиот | ἰδιώτης, «частный» — узел, замкнувший обмен: форк без обратного мержа, орган без синапсов. Про связность, не про интеллект |
| Commons | κοινός, «общий» — этимологический антоним идиота; режим существования через общий обмен |
| Орган | upstream-проект, подключённый к organism в одном из режимов ниже |
| Режим органа | `dependency` (в теле, только permissive) · `adapter` (наш тонкий код вокруг) · `external` (вне тела: AGPL/fair-code) · `reference` (изучение) · `substrate` (среда, не трогаем) · `education` (репродукция клеток) |
| Геном | спеки и навыки; поведение живёт в спеках, код — производная (SDD) |
| Ствол мозга | канонический цикл агента PLAN → ACT → OBSERVE → REFLECT (SPEC-0001) |
| Синапсы | MCP-шлюз; каждый орган — MCP-сервер; вызовов мимо синапсов нет (SPEC-0002) |
| Кровь | поток событий-конвертов: кто, что, зачем, цена в токенах/секундах (SPEC-0003) |
| Дневник | read-проекция крови в человеческом языке (`blood/diary.py`, SPEC-0003 v0.9.0 п.12): семь вопросов действия — что сделано; кто инициировал; когда; цена; результат; можно ли отменить (честно «не заявлено»); чем подтверждён (id конвертов). План ≠ предложение ≠ отказ ≠ факт; «успешно» без проверяемого факта запрещено; кровь дневник не переписывает |
| Конверт крови | JSON-объект с обязательной `cost`; событие без цены недействительно |
| Метаболизм | локальный инференс (ollama, llama.cpp, transformers) |
| Иммунитет | лицензионный барьер, supply chain, политика секретов ([PROVENANCE.md](../PROVENANCE.md)) |
| Тест отключения | орган заменяем за часы — иначе это паразит, а не орган |
| Обратный мерж | возврат улучшений в upstream; форк без него — идиот-ветка |
| Линза | одна из шести ролей оценки органа ([lenses.md](lenses.md)) |
| Спайк | короткий эксперимент с метриками и критерием выхода ([spikes.md](spikes.md)) |
| Definition of One | каждый вызов через синапсы · поведение в спеках · замена за часы · организм рисует себя сам |
| Клетка | участник (человек или агент), работающий по трём законам организма |
| Снимок | датированная выборка живых данных; не путать с живым счётчиком |
| Система (орган пакета) | функция организма из пакета Human Membrane (endocrine, limbic, olfactory, immune, sleep, mirror, economy, swarm, conscience, creative); слово «орган» остаётся за внешней зависимостью `organs/`, функции пакета называются системами (ADR-0013, отображение — [human-membrane-synthesis.md](human-membrane-synthesis.md)) |
| Бюджет | лимиты метаболизма (`brainstem/budget.py`): токены и секунды. Ресурс внимания Человека называется «внимание», не бюджет (ADR-0013) |
| Полномочия | процессные скоупы fs/network/process и их страж (`synapse/authority.py`, SPEC-0002). Одобрение Человека перед необратимым — «одобрение» (approval), строится поверх полномочий (ADR-0013) |
| Намерение | `idempotency_key` конверта крови: имя намерения события; повторный append с тем же ключом не повторяет эффект (SPEC-0003 п.9, A01) |
| Честный отказ | данные, а не стыд: `veto` (сказано «нет»), `halt` (остановились), `error` (ошиблись), `security.violation` (остановлено стражем); счётчик провалов — `blood/refusals.py` (W-0021). Успешный жанр (`plan`/`act`/`observe`/`reflect`/`boot`/`shutdown`/`organ.*`) в счёт не входит |
