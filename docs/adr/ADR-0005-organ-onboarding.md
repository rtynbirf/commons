# ADR-0005: Ритуал подключения органа — лицензия, пульс, приёмка

Статус: принято · Дата: 2026-11-01

## Контекст

0.2.x умеет исполнять цикл и имеет адаптеры, но «подключённый орган» ничем не отличался
от «объявленного в манифесте». Разница должна быть механической и публичной: живой орган
выполнил реальное действие через синапсы, и это записано в крови. Опыт первого пульса
(markitdown, 2026-11-01) показал и практические ловушки: `convert_to_markdown` требует
схему `file:` URI, инициализация сервера занимает секунды, цену орган не считает сам.

## Решение

Орган считается **подключённым**, когда прошёл три шага ритуала:

1. **Иммунитет.** Лицензия перепроверяется живым API (`GET /repos/{owner}/{repo}/license`)
   в момент подключения (не «на дату прошлого исследования»): дата, SPDX, путь файла —
   в `PROVENANCE.md` §4. NOASSERTION/copyleft/fair-code — по правилу входа (PROVENANCE §5).
2. **Пульс.** Воспроизводимый прогон (`scripts/<organ>_pulse.py` или общий бегун) выполняет
   одно реальное действие органа целиком через синапсы: цикл → шлюз → адаптер → орган.
   Артефакты прогона коммитятся в `runs/<дата>-<пульс>/`: вход (наш собственный),
   `blood.jsonl`, выход, `report.md` с G1-реконструкцией и ценой.
3. **Приёмка.** Коммитнутый пульс становится pytest-приёмкой (`tests/test_first_pulse.py`
   и наследники): схема крови, G1, отсутствие событий без цены, соответствие `output.md`
   крови. CI проверяет пульс на каждом пуше — кровь не подделать задним числом.

Контракт пульса: входной документ создаёт сам организм (провенанс: наш труд, не чужой
контент); манифест обновляется (`note: подключён <дата>`); карточка органа меняет статус;
`ROADMAP.md` отмечает подчекбокс.

## Альтернативы

- Считать орган подключённым после успешного healthcheck — отклонено: здоровье без
  действия не доказывает обмен (это и есть определение идиота: способность есть, обмена нет).
- Писать результаты в issue, а не в репо — отклонено: кровь должна жить в теле, issue
  внешнего хостера — не append-only журнал организма.
- Не коммитить артефакты (воспроизводить на лету) — отклонено: пульс с настоящим органом
  не воспроизводим в CI без органа; коммитнутая кровь — вещественное доказательство.

## Последствия

**Положительные:** статус «подключён» проверяем механически; кровь накапливается как
история жизни организма; каждая новая интеграция усиливает приёмки, а не ослабляет.
**Отрицательные / цена:** `runs/` растёт с каждым пульсом (входы держим минимальными);
для органов с тяжёлым окружением (браузер, GPU) пульс переносится на машину организма —
артефакты коммитятся оттуда, CI проверяет их целостность.
**Обратный мерж:** ловушки подключения (например, `file:` URI markitdown) — кандидаты
на багрепорты/доки в upstream (ADR-0001).
