# ADR-0007: Движки памяти — два слоя, кандидаты и спайк S6

Статус: принято · Дата: 2026-11-02

## Контекст

M2 «Нервная система» требует память организма (ROADMAP.md): граф знаний + векторный индекс —
поведение зафиксировано SPEC-0005, выбор движка — здесь. Выбор нельзя выдумывать: факты —
только из живого GitHub API с датой (PROVENANCE §2), решение — только по замеру, а не по вере.

## Решение

Память — два слоя с раздельными движками (оба — органы в `synapse/mcp-manifest.yaml`, SPEC-0005):

1. **Граф знаний.** Кандидат — Graphify-Labs/graphify: Apache-2.0, верифицирован живым API
   2026-11-01 (PROVENANCE §3, 140 345 ⭐).
2. **Векторный индекс.** Кандидат выбирается из таблицы ниже. Критерии выбора:
   - встроенный режим без обязательного сервера (орган живёт в теле, режим `dependency` — SPEC-0002);
   - OSI-лицензия, перепроверяемая живым API (закон иммунитета — ADR-0001, PROVENANCE §4);
   - ≤ 1 процесс на движок (тело не разводит зоопарк процессов);
   - локальные данные по умолчанию (G3 SPEC-0005).

Кандидаты (GitHub API, 2026-11-02, звёзды на ту же дату):

| Кандидат | Лицензия | Звёзды | Профиль |
|---|---|---:|---|
| asg017/sqlite-vec | Apache-2.0 | 8 232 | «vector search SQLite extension that runs anywhere» |
| chroma-core/chroma | Apache-2.0 | 29 616 | — |
| lancedb/lancedb | Apache-2.0 | 11 824 | «embedded retrieval library» |
| qdrant/qdrant | Apache-2.0 | 35 366 | — |

## Базовая линия

Базовая линия — stdlib sqlite3 (brute-force cosine KNN), замеряемая в CI харнессом
`spikes/s6-memory/measure.py` (0.5.0). Финальный движок выбирается метриками S6 на живом хосте
организма; результат — отдельной записью в README спайка, не в этом ADR.

## Последствия

**Положительные:** память наследует G1–G3 SPEC-0005 — воспроизводимость replay-ем крови,
заменяемость движка правкой манифеста, локальность по умолчанию.
**Отрицательные / цена:** выбор векторного движка отложен до метрик S6 на живом хосте;
eviction по бюджету — M3 (SPEC-0005, п.6); режим памяти «наружу» — отдельный ADR.
**Связь:** ADR-0001 — движки памяти остаются на upstream, не форкаются; ADR-0003 — все
кандидаты Apache-2.0, встраиваются в тело без лицензионных конфликтов.
