## [0.5.0] — 2026-11-02

### Added

- **Геном памяти**: `specs/SPEC-0005-memory.md` — «Память — производная крови»: два слоя
  (граф + вектора), движок памяти — орган в манифесте, кровь — истина, память — кэш-советник;
  гарантии G1 replay / G2 заменяемость / G3 локальность. События жизни (boot/health/shutdown
  PID 1) оседают в память наравне с обменами.
- **ADR-0007**: движки памяти — два слоя; критерии выбора векторного движка (встроенный режим,
  OSI-лицензия, ≤1 процесс, локальные данные); четыре кандидата верифицированы живым API
  2026-11-02 (все Apache-2.0): sqlite-vec, chroma, lancedb, qdrant; финал — метриками спайка S6.
- **Спайк S6 — харнесс**: `spikes/s6-memory/` — базовая линия stdlib sqlite3 (brute-force
  cosine KNN, 200×384, seed 42) замеряется в CI; живые движки — только при установке,
  иначе `NO_ENGINE` (код 2) — цифры не выдумываются.
- **Второй автопортрет**: `scripts/organ_map.py` → `docs/organ-map.excalidraw` — карта
  организма в excalidraw генерируется из живого реестра (36 органов, 13 систем);
  детерминированная генерация (байт-в-байт), гейт свежести `--check`, приёмки в CI.
- Нумерация генома продолжена с учётом волны PID 1: SPEC-0005/ADR-0007 (SPEC-0004/ADR-0006 —
  за живым организмом, 0.4.0).

### Changed

- Всего **80 приёмок** (70 после 0.4.0 + карта ×5 + S6 ×5); REUSE 3.3 compliant.
- `PROVENANCE.md` §3: четыре векторных движка добавлены в верифицированную матрицу (2026-11-02).
- `docs/spikes.md` 0.5.0: шесть спайков (S1–S6).
- `README.en.md`: версия появления PID 1 исправлена на 0.4.0.

## [0.4.0] — 2026-11-02

### Added

- **SPEC-0004: PID 1 — живой организм** (спека до кода) + **ADR-0006: ЧЕЛОВЕК=PID=1**.
  Организм получил ритм жизни: `BOOT → HEARTBEAT → SHUTDOWN`; init'ом остаётся человек —
  юнит-файлов и автостарта в репо нет, запуск и убийство — только его руки.
- `brainstem/pid1.py` + `scripts/pid1.py` (и команда `commons-pid1`): демон-сердцебиение —
  каждые `interval` секунд опрашивает healthcheck всех органов манифеста
  (`organ.health` с замером секунд); недоступный орган не останавливает сердце.
- **Кровь пишется в момент события** (SPEC-0004 п.5): `Journal.attach()` — append-only файл
  `runs/<дата>-pid1/blood.jsonl`; сессии одного дня живут в одном файле, различаясь `trace_id`;
  смерть процесса не теряет конвертов. Отчёт сессии: `report-<trace_id>.md` (G1-реконструкция).
- **Одиночность организма** (G6): `blood/pidlock.py` — файловый lock с pid; живой владелец =
  `veto` + `shutdown(second_instance)`, выход 1; протухший lock (владелец мёртв) заменяется.
- **Смерть по-записанному** (G4): SIGTERM/SIGINT перехватываются → `shutdown(signal:…)`,
  выход 0; бюджет (G3) → `shutdown(budget:…)`, выход 2; `max_beats` → выход 0.
  Органы-процессы закрываются `shutdown()` адаптера — не сиротами.
- Типы крови `boot` и `shutdown`; эмитент `pid1` (SPEC-0003 v0.2.0, схема +2 значения enum).
- `runs/2026-11-01-pid1/` — первые живые сердцебиения: две сессии в одной крови, все конверты
  валидны, органы честно `healthy=false` (в песочнице не развёрнуты — и это записано).
- `tests/test_pid1.py` — 13 приёмок SPEC-0004 (boot/beat/файл-в-момент-события/veto-второго/
  протухший lock/сигнал/дети/бюджет-выход-2/граница бюджета/таймауты stdio/цикл замен). Всего 70.

### Changed

- **SPEC-0002 v0.3.0, п.7**: орган-процесс умирает по `shutdown()` организма; таймауты —
  необязательное поле `timeouts: {init, call}` манифеста; зависший орган обязан обнаруживаться.
- `synapse/adapters/mcp_stdio.py`: таймауты теперь честные — селекторное ожидание строки
  (POSIX selectors), зависший процесс завершается самим адаптером (SIGTERM → SIGKILL);
  адаптер реализует `shutdown()` (SPEC-0002 п.7).
- `synapse/gateway.py`: защита от циклов в таблице замен (SPEC-0002 п.3) — орган дважды в одной
  цепочке замен не появляется; цикл = `error` + `OrganUnavailable`, а не рекурсия.
- `brainstem/loop.py`: граница бюджета включена — проведённое ровно в лимит = исчерпан (`>=`).
- `.gitignore`: `runs/.pid1.lock` — живой lock тела, состояние машины, не репо.

### Fixed

- Аудит 2026-11-02 (внешняя ревизия): таймаут `MCPStdioAdapter._rpc` объявлялся, но не
  соблюдался — `readline()` блокировался бесконечно; зависший орган останавливал тело.
- Аудит 2026-11-02: рекурсия замен без защиты от циклов (латентная — ловится фланкирующим
  healthcheck'ом); бюджет проходил ровно по границе.
- Метка CI-джобы тестов больше не протухает: вместо устаревшего числа — «приёмки SPEC-0001..0004».
