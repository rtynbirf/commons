# SPEC-0009: Трансплантология — донорский протокол органов

Статус: принято (спека до кода) · Версия: 0.1.1 · Дата: 2026-11-02 (v0.1.1: реестр типирован до конца — 18 карт; непотипированное донорство отвергается гейтом)
Относится к: ADR-0011, ADR-0001, SPEC-0006 (входной иммунитет), AGENTS.md п.2, ROADMAP M3

## Назначение

Иммунитет (SPEC-0006) решает, **что входит** в тело. Трансплантология решает, **куда тело
отдаёт свою кровь** — патчи, улучшения, документы, созданные организмом для upstream-органов.
AGENTS.md п.2 и ADR-0001 предписывают: «органы не форкать, улучшения отправляются в upstream».
Но ни одна конвенция до сих пор не спрашивала, какой ценой upstream берёт этот дар.

Ответы upstream делятся на два рода. **DCO** (`Signed-off-by`) — рукопожатие: «кровь моя,
я отвечаю за неё» — человек заверяет человека. **CLA** — ошейник: «права на мою кровь
переходят хозяину репозитория» — человек подписывает корпорации. COMMONS делает для человека,
а не для корпораций и государств: тело дарит кровь только по рукопожатию.

Принцип взаимности: **дарим тому, кто дарит**. Донорство в upstream с ограниченной
или несвободной лицензией — работа без адресата: труд уходит туда, где им владеют
на произвольных условиях.

## Контракт

1. **Карта донорства — данные.** Каждому органу, которому тело может отправить кровь,
   соответствует карта в `organs/donation.yaml`. Нет карты — донорства нет
   (G1 fail-closed: орган без карты не готов к донорству).
2. **Протокол органа.** `protocol` — как upstream принимает кровь:
   - `dco` — upstream требует DCO (рукопожатие);
   - `none-observed` — ошейников не обнаружено (живая проверка с датой);
   - `cla` — upstream требует CLA (ошейник);
   - `unverified` — типирование не проводилось.
3. **Решение тела.** `decision`:
   - `donate` — кровь отправляется в upstream;
   - `patch-inside` — патч живёт внутри организма (в адаптере, обвязке, собственных файлах);
     upstream не трогается;
   - `consume-only` — тело только потребляет орган (внешний узел), донорство не имеет смысла.
4. **Вердикт — чистая функция.** Механизм — `immune/donation.py`: `(карта, реестр, матрица)
   -> Decision(ok, rule, reason)`. Никакой сети, времени и окружения — вердикт
   воспроизводим байт-в-байт. Факты типирования живут в `evidence` карт, не в коде.
5. **Evidence с датой.** Каждая карта несёт `evidence` — не менее одной записи
   `{date, url, fact}`: где, когда и что именно проверено живым чтением upstream
   (PROVENANCE §2: данные не код, факты — с датой). Карты без доказательств —
   нарушения, не пропуски.
6. **Правила вердикта:**
   - `protocol: cla` + `decision: donate` → отказ (`collar`): кровь не подписывает ошейники;
   - `protocol: unverified` + `decision: donate` → отказ (`untyped`): сначала типирование;
   - `decision: donate` + лицензия органа вне `allowed` матрицы иммунитета → отказ
     (`not-mutual`): дарим тому, кто дарит;
   - орган карты отсутствует в `organs/registry.yaml` → отказ (`unknown-organ`):
     кровь отдаётся органам тела;
   - дубликат карты → отказ (`duplicate`);
   - повреждённая или неполная карта → отказ (`missing`), молчаливых пропусков нет;
   - согласная карта → `ok` с `rule` из `donate` / `patch-inside` / `consume-only`.
7. **CI-гейт.** `python -m immune.donation` (консольный скрипт `commons-transplant`) входит
   в конвейер: непройденный вердикт — ненулевой код возврата, красный PR.
8. **Одно направление.** Спека описывает только исходящую кровь. Входящие контакты —
   зона SPEC-0006; реестр органов и режимы — источник истины о составе тела.

## Гарантии

- **G1 Fail-closed.** Орган без карты к донорству не готов; карта без evidence — отказ;
  повреждённые данные — отказ гейта, не пропуск.
- **G2 Данные, не код.** Новая карта или смена протокола — правка YAML без правки кода;
  приёмка доказывает это на tmp-карте.
- **G3 Наблюдаемость.** Каждый вердикт несёт `rule` и человекочитаемую `reason`; итог гейта —
  машина-читаемая строка `TRANSPLANT: N ok, M failed` (при отказе — `TRANSPLANT: FAIL (…)`).

## Отказные режимы

| Ситуация | Поведение |
|---|---|
| Орган карты не в реестре | отказ `unknown-organ` |
| `protocol: cla` + `donate` | отказ `collar` — ошейник не подписывается |
| `protocol: unverified` + `donate` | отказ `untyped` — сначала типирование |
| `donate` + лицензия вне `allowed` матрицы | отказ `not-mutual` — дарим тому, кто дарит |
| Нет evidence / пустой fact / нет даты / url не https | отказ `missing` |
| Дубликат repo | отказ `duplicate` |
| donation.yaml повреждён | гейт падает с ошибкой загрузки, PR красный |

- [x] Каждый repo карт существует в живом реестре органов.

- [x] У каждой карты есть `evidence` с датой, https-URL и фактом.
- [x] Подмена протокола в tmp-карте меняет вердикт без правки кода (G2).
- [x] Карта без обязательных полей и орган вне реестра — отказ (G1).
