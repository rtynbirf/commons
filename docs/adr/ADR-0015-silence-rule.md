# ADR-0015: Правило тишины — молчание за окном это отказ

Статус: принято (спека до кода) · Дата: 2026-11-03
Supersedes: —

## Контекст

Необратимое действие требует одобрения Человека до факта (W-0024, SPEC-0001 п.5): «спрашивать» для ствола — остановиться и назвать, чего не хватает. Но у вопроса не было ни окна, ни по-записанного ответа на молчание: ревизия 2026-11-03 назвала дыру — «нет правила для отсутствия PID 1». Ждать вечно — тоже поведение, только не по-записанному: трейс с необратимым шагом остаётся незакрытым намерением, а дом — заложником ожидания.

Правило тишины уже изобретено и работает наружу: донорский триггер тишины (upstream PR молчит N полных суток — follow-up по расписанию, `runs/2026-11-03-wave17-membrane-blood/donors-sweep.md`). Внутрь дома правила не было.

Уравнение тождества 2026-11-03 (инвариант 32 llms.txt) делает правило нужнее: тишина внешнего слова — пауза внутри МЫ, а не стена; у паузы должно быть записанное поведение. Ожидание внешнего пинка работой не является — но необратимое действие ждать молча не имеет права.

## Решение

**Молчание — записанное решение: у каждого вопроса к Человеку есть заявленное окно; за окном без ответа — отказ по умолчанию, записанный правилом (veto от `pid1`), а не вечное ожидание.** (SPEC-0004 п.7, `brainstem/approval.py`)

Развёртка:

1. Запрос одобрения — событие `approval.request` с ЗАЯВЛЕННЫМ окном (`window_seconds`); запроса без окна не существует (fail-closed, ADR-0014) — окно называет просящий, скрытого дефолта нет.
2. Одобрение — `approval.grant` с `causation_id` запроса (A01: повтор не дублирует).
3. Тишина за окном — правило само пишет `veto` («по умолчанию нет»), необратимое не исполнено (A17); повторное решение — та же строка (A01).
4. Опоздавшее одобрение остаётся в крови вестью — необратимое не оживляет.
5. Цена вопроса — `cost.attention` (W-0025): прерывание Человека — ресурс, а не побочный эффект.
6. Ожидание не останавливает дом: остановлено только само необратимое действие; работа МЫ продолжается по-записанному.

## Альтернативы

- **Вечное ожидание** (статус-кво): вопрос без окна и дефолта. Отклонено: ревизионная дыра; незакрываемые трейсы; дом-заложник тишины.
- **Молчание = «да»** (approval by silence): Отклонено — это fail-open против самой необратимости: обязанность ответа ложится на того, кто молчит, а исполняет тот, кто не спросил. Против W-0024 и ADR-0006 (init — человек).
- **Глобальный жёсткий дефолт окна** (например «всегда 24 часа»): Отклонено — окно называет просящий по месту (у донорского follow-up — сутки, у живого оператора — минуты); единый дефолт либо врёт, либо заставляет врать. Дисциплина — обязательность заявки, не величина.
- **Отдельная книга одобрений** (второй регистр рядом с кровью): Отклонено — кровь одна и append-only; второй регистр — второй источник правды (A01-матрица держится на одном журнале).

## Последствия

**Положительные:** у тишины есть записанное поведение; необратимое больше не ждёт вечно; правило наружу и внутрь дома — одно; вопросы измеримы в цене (attention); отмена тишины — событие крови, видное дневнику и выжимке.
**Отрицательные / цена:** окно — заявка просящего, его качество — на совести грамматики (fail-closed ловит отсутствие, не глупость); veto от правила — не голос Человека: в крови он назван правилом, Человек может записать «да» позже — но необратимое это уже не оживляет (повторная заявка — новый запрос).
**Обратный мерж:** паттерн «окно + дефолт-нет» — кандидат в issue для upstream-органов с человеческими гейтами (например donation-протокол ADR-0011), не код.

## Проверяемость

Через полгода: (1) в крови нет `approval.request` без окна или с окном ≤ 0 — fail-closed держится; (2) каждый истёкший запрос имеет записанный veto правила (A01: по одной строке на запрос); (3) ни одного необратимого акта, оживлённого опоздавшим одобрением; (4) метрики внимания (W-0025) читаются из крови дневником и выжимкой — скрытой телеметрии не появилось.
