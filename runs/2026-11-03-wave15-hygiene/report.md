# Контрольный забег Ф-0 — стык волн №15/№16

**Дата:** 2026-11-03 · **База:** 0.35.0 (их волна №16) · **Дельта:** 0.35.1 (SPEC-0003 v0.6.0, угловые приёмки, глоссарий 0.2.0)

## История стыка (честно)

Ревизия ревизора разметила Ф-0 — пять пунктов гигиены (P0). Директива Человека:
«ГОНИ ВОЛНУ, КОСЯКИ ПРАВЬ ЧТОБ РЕПА БЫЛА ОБРАЗЦОВО ПОКАЗАТЕЛЬНОЙ». Волна №15
(этот забег) закрыла Ф-0 **параллельно и независимо**: свой красный прогон
(9 красных приёмок A01 на нетронутом коде + модуль честности отсутствовал),
своя реализация (память намерений журнала, `blood/honesty.py`, свои ADR-0013/0014,
uname-проба Landlock). Пуш отбит rebase-защитой: на main уже стояли релизы
параллельного интегратора — их волна №15 (0.34.0, разбор пакета Human Membrane,
хотёлки W-0022–W-0025) и их волна №16 (0.35.0, **Ф-0 5/5**).

По стык-дисциплине волны №13 («их релизы сохранены без переписывания,
параллельный вариант отступает более консервативному решению») **их база принята
целиком**, мой параллельный код выметен. Их решения точнее в двух местах:

1. **Landlock-проба**: их живой syscall 444 `landlock_create_ruleset` → ENOSYS —
   показание ядра, а не версия из `uname` (моя); факт в SPEC-0002 п.11 их строкой.
2. **A17 (неизвестный тип крови)**: их ADR-0014 развёл режимы границей
   «писать/читать» — пишущий контур fail-closed без исключений, файл append-only
   помнит всё, читатель честно называет чужое `skipped` (сохранено — не исполнено).
   Консервативнее моего «сохранить-и-назвать под `observe`» (не заводит
   интерпретацию чужого языка в собственной крови). Их ADR-0013 (словарь дома)
   и их `blood/refusals.py` приняты; мой `blood/honesty.py`, мои ADR-файлы,
   мои дубли-приёмки выметены.

## Остаток дельты забега (что их базе не хватает)

1. **SPEC-0003 v0.6.0 п.9** — контракт идемпотентности, который их код
   уже исполняет, а спека не знала (их релиз 0.35.0 не правил SPEC-0003;
   схема в описании поля ссылалась на SPEC-0003 без п.9). Спека догнала код:
   дедуп по `id`/ключу, конфликт по `id` с другим содержанием, скоуп памяти —
   журнал, восстановление при `attach()`/`from_jsonl()`. Словарь типов дополнен
   их законом честного отказа (W-0021, `blood/refusals.py`).
2. **Угловые приёмки** `tests/test_blood_dedupe_edges.py` (6) — грани, которых
   нет в их сюите: скоуп ключа = журнал, не трейс; разные ключи при одинаковой
   нагрузке — два конверта; повтор ключа с другим payload возвращает первый
   конверт (записанное не подменяется); пустой ключ роняется схемой; `make()`
   несёт ключ; `from_jsonl` → `append` дедупится.
3. **Глоссарий 0.2.0** — пять записей (система, бюджет, полномочия, намерение,
   честный отказ) — их релиз не правил словарь.
4. **Контрольный забег** — этот файл и сцены: независимая перекрёстная проверка
   их кода третьим путём (их живой прогон — 4 конверта; здесь — 9 сцен).

## Сцены (на ИХ коде, 9 зелёных / 0 красных)

1. A01 дедуп: повторный ключ — журнал 1 конверт, файл 1 строка, id совпал;
2. A01 resume: после reopen ключ не дописал — возвращён id записанного;
3. A01 совместимость: конверт без ключа живёт как прежде;
4. A01 разные ключи — оба конверта;
5. W-0021 их счётчиком по живой крови А/Б: error 3 + halt 3 +
   security.violation 3 = 9, трейсов с провалами 3/3 — сверено с ручным подсчётом;
6. W-0021 red-run: veto 2 + halt 2 + error 5 + security.violation 3 = 12;
7. W-0021 знаменатель: провалов 9 из 33 конвертов;
8. Landlock-проба: uname-показания согласованы с их живым syscall-фактом
   (ENOSYS на 5.10.134);
9. кровь забега: 68 конвертов за три сессии (22 + 23 + 23 — повторные сессии
   продолжили цепочку по п.7), 0 гэпов, chained.

## Граница семантики, названная забегом (не overturn)

Их счётчик берёт `error` в провалы — «честный отказ это данные». Забег называет
живой пример жанра: А-группа А/Б содержит `error → organ.replace → успех`
(сломанный орган заменён резервом, задача решена) — resilient-путь попадает
в счёт провалов наравне с отказом до факта. Это не баг их релиза — это граница
жанра «провал»: счётчик считает провалы, а не классифицирует траектории.
Уточнение классификации (например, по `payload.reason` или связке с
`organ.replace`) — кандидат Ф-2 (conscience), не правка задним числом.
