## Замеры живьём (кровь: blood.jsonl, 10 конвертов, chained + hashed, опечатана якорем)

### SPEC-0011 — одна проходка, все функции структуры (W-0037)

Эталон плана «Движок·самоприменение» (преемственность с поставкой движка):

- **Расписание**: T = 9.0; критический путь A→B→D→E→F→G; резервы
  R = T − K⁺ − K⁻ + d, R(C) = 0.5, остальные 0 — один пропагатор на зеркале
  Gᵀ, не второй алгоритм.
- **Ансамбль путей** (4 вопроса, 4 полукольца, одна проходка): число путей
  3 (COUNT), надёжнейшая траектория A→C→G = 0.960498 (max,×), P(z) =
  z³ + z^8.5 + z⁹ (ℝ[z]), фронт Парето (3.0, 0.960498).
- **Критичность**: плотность мировых линий c(v) = n⁺(v)·n⁻(v)/N — A и G
  по 1.0, средина пути 0.667, C — 0.333 (сверху: критпуть).
- **Термодинамика**: f(β=1) = 9.4756 → f(β=10) → f(β=100) = 9.0000 —
  тропический предел: критический путь — основное состояние ансамбля путей.
- **Крэшинг-контур**: бюджет 5.0 — пять ходов B→D по 0.5, T: 9.0 → 6.5,
  потрачено ровно 5.0; каждый ход назван в истории, план вызывающего не
  тронут (контур работал на копии).
- **Эквивалентности**: проходка Кана = matvec по слоям (GraphBLAS-жанр) =
  покой ячеек (Radul/Sussman); Клейни-замыкание (min,+) A→G = 5.0 = sweep.
- **Кольцо**: усиление петли β^L = β³ = 1/8 поймано числом —
  K(Z1) = 0.571429 = β/(1−β³) за 55 итераций; расходимость при β ≥ 1
  названа честным `converged=False` (отдельная приёмка).
- **Универсальная теорема**: 200 случайных планов × 4 полукольца × все
  вершины = **5600 сверок с тупым перебором путей, расхождений 0**.
- **Тест отключения (G2)**: греп ядра дома (brainstem, synapse, blood,
  memory, immune, pipeline, openclaw) на `taskgraph` — 0 попаданий.

## Косяки, пойманные живыми прогонами волны (названы поимённо)

1. `Cell.__slots__` без поля `sr` — ячейка не строилась (AttributeError на
   первом прогоне) — зашито.
2. `graph.dep()` ссылался на `INF` без импорта — NameError на первом
   графе с петлёй-запретом — зашито.
3. `criticality` без нейтрального ε умножал COUNT-путь на вес ребра 0.5 —
   «половина пути» — fail-closed вердикт «нет путей» — зашито нейтральным
   переносом (урок части 1 повторён живьём).
4. Контракт `closure.wfun` разъехался с приёмкой (wfun(w) против
   wfun(u,v,w)) — TypeError — контракт унифицирован до (u, v, w).
5. BOOL-перенос в первой редакции приёмки теоремы игнорировал источник
   (`eps → True` даже из лжи) — «достижимость из ничего»; тест исправлен
   на честный перенос Ku, движок не тронут.
6. Инкрементальная приёмка ячеек ждала числа с потолка — пересчитаны
   честной проходкой (F: 4.0 → 6.0 после добавления зависимости).
7. Регэксп fail-closed-приёмки матчил английское слово, дом говорит
   по-русски («длительность») — приёмка выправлена под словарь дома.
8. `criticality` на плане без рёбер не краснел (тривиальный путь вершины
   на себя — честный путь нулевой длины); граница сдвинута на пустой план
   — краснеет поимённо.
