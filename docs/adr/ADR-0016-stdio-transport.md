# ADR-0016: Локальный транспорт — stdio + localhost-http; наружного шлюза нет

Статус: принято · Дата: 2026-11-03 · Источник: ТЗ-3.1 (Ф-3, волна №29),
 Asi03-границы пакета «Human Membrane»

## Контекст

ТЗ-3.1 предлагало развилку: MCP HTTP-транспорт с OAuth 2.1
audience-binding — или честный ADR об отказе. Живой факт дома
(замер манифеста): метаболизм говорит http к localhost-эндпоинтам
(ollama `:11434`, llama.cpp `:8080`), руки openclaw — http к loopback
(bind 127.0.0.1, токен только env — `openclaw/reference/effector-policy.json`),
сенсорика и эффектор файлов — stdio-процессы. Заявлять «только stdio» —
значит солгать крови дома.

## Решение

Дом говорит **локальным транспортом**:

1. **stdio** — органы-процессы (markitdown, browser-use): MCP поверх
   stdin/stdout, страж полномочий (SPEC-0002 п.8) сидит в самом процессе.
2. **http — только к localhost/127.0.0.1-эндпоинтам органов**: метаболизм
   и руки живут на той же машине, что тело; порты сужены скоупами
   полномочий (SPEC-0002 п.8 v0.5.0, волна №9), токены — только env (G2).
3. **Наружного HTTP-шлюза у организма нет.** MCP HTTP-транспорт с OAuth 2.1
   audience-binding — наружный контур: он нужен, когда телом пользуются
   через сеть — право и хост Человека (PID 1). До живой необходимости
   наружный транспорт не строится: незаявленная поверхность атаки — не
   поверхность, а дыра; её честнее не иметь, чем прикрыть флагом.

## Границы (названы, не прикрыты)

- Живой хост с настоящими органами и наружной необходимостью — за
  Человеком (граница как у ТЗ-0.1/ТЗ-1.4: машина не приписывает замер и
  не строит наружную дверь без воли).
- localhost-http защищён скоупами полномочий `{hosts, ports}` (точное
  совпадение порта) и fd-гигиеной детёнышей (SPEC-0002 v0.10.0, волна №14):
  сокет-дескриптор при `network != any` прерван до рождения.
- Если Человек потребует наружный транспорт — новый ADR поверх этого
  (изменение воли — только новым ADR, как в ADR-0015 о порядке законов).

## Последствия

- Приёмка машинно: все http-органы манифеста дома обязаны смотреть в
  localhost/127.0.0.1 (`test_house_manifest_is_local_only`) — наружный
  endpoint без нового ADR красит PR.
- SPEC-0002 остаётся геномом транспорта: грамматика transport/endpoint
  описана там; этот ADR — воля дома о том, каких транспортов не будет
  до отдельного слова Человека.
