# ADR-0006: ЧЕЛОВЕК=PID=1 — организм как процесс с ритмом

Статус: принято · Дата: 2026-11-02
Supersedes: —

## Контекст

До 0.2.2 организм исполнялся задачно: цикл SPEC-0001 запускался бегуном (`first_pulse`, `organism_pulse`) и умирал молча — процесс завершался, кровь закрывалась, «жизнь» равнялась одному прогону. Инвариант тела говорит: событие без цены не существует. Обратное тоже верно: существование без записи недопустимо — процесс, умерший без события, выпадает из провенанса.

В Unix у процесса с PID 1 особая роль: он не умирает от непойманных сигналов, собирает сирот; при его смерти ядро паникует. Организму нужен собственный ритм — но кто в этом организме init?

Третья сила: в репо работает несколько субъектов-агентов одновременно (мандат 2026-11-02). Организм один — значит, его жизнь должна быть одиночной и наблюдаемой, а смерть — всегда записанной.

## Решение

**ЧЕЛОВЕК=PID=1: организм получает собственный процесс с ритмом (SPEC-0004), но init'ом остаётся человек — организм никогда не назначает себе вечность.**

Развёртка:

1. `brainstem/pid1.py` — демон-сердцебиение: BOOT → HEARTBEAT (`organ.health` по всем органам манифеста) → SHUTDOWN; кровь пишется на диск в момент события (append-only), не снимком.
2. Смерть всегда записывается: SIGTERM/SIGINT перехватываются → `shutdown(signal:…)`; бюджет → выход 2; второй экземпляр → veto + выход 1. Сироты-процессы собираются: `shutdown()` органов-процессов (SPEC-0002 п.7).
3. Одиночность — файловый lock с pid: живой владелец = veto второму; протухший заменяется.
4. Никаких юнит-файлов/systemd/автостарта: только человек запускает `python3 scripts/pid1.py` и только человек его убивает.

## Альтернативы

- Статус-кво (задачные прогоны) — организм не «жив», а «выполняется»; органы не наблюдаются во времени; смерть немая. Отклонено: нарушает дух инварианта цены.
- systemd-юнит в репо — организм назначает себе вечность и перестраивает иерархию: init'ом становится менеджер служб, а не человек. Против G5.
- Supervisor-петля внутри ствола мозга — двойная петля управления: SPEC-0001 остаётся единственным источником агентности; PID 1 — ритм, не интеллект.

## Последствия

**Положительные:** организм наблюдаем во времени (health-трейс всех органов); каждая остановка — в провенансе; органы-процессы не осиротевают; зависший орган больше не останавливает тело (таймауты MCP-stdio включены — дыра из аудита 2026-11-02 закрыта).
**Отрицательные / цена:** SIGKILL человека обходит кровь — неотслеживаемая смерть остаётся возможной (принимаем: провенанс не бывает абсолютным, право молчания — у человека); lock-файл — новое состояние тела (gitignore); таймауты реализованы POSIX-селекторами — переносимость вне Linux ограничена.
**Обратный мерж:** паттерн таймаутов для stdio-JSON-RPC — кандидат в issue для upstream-органов (markitdown-mcp, browser-use-mcp), не код.

## Проверяемость

Через полгода: (1) каждая остановка организма в `runs/*-pid1/` имеет событие `shutdown` — ноль «немых смертей»; (2) ни одного осиротевшего markitdown-mcp после тестов; (3) kill -9 по-прежнему возможен только рукой человека.
