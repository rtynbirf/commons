# SPEC-0001: Ствол мозга — канонический цикл агента

Статус: принято (спека до кода) · Версия: 0.2.0 · Дата: 2026-11-02 (v0.2.0: G3 алерты и per-call лимиты из манифеста — M3)
Относится к: ADR-0001, ADR-0002, SPEC-0002, SPEC-0003

## Назначение

Единственный источник агентного цикла в организме. Эффекторы и референсы (openclaw, claude-code, opencode) изучаются, но цикл реализуется один раз — здесь. Никакой орган не решает сам, что делать организму.

## Контракт

Цикл: `PLAN → ACT → OBSERVE → REFLECT → (PLAN | HALT)`.

1. **PLAN**: выбор следующего действия только из инструментов, объявленных в `synapse/mcp-manifest.yaml`. Инструмента нет в манифесте — действия нет (событие `veto`).
2. **ACT**: вызов органа строго через MCP-шлюз (ADR-0002). Прямые вызовы органов запрещены.
3. **OBSERVE**: результат нормализуется в конверт крови (SPEC-0003) с заполненной `cost`.
4. **REFLECT**: сравнение результата с намерением; событие `reflect`; решение — новый PLAN или HALT.

## Гарантии

- **G1 Трассируемость.** Каждый переход цикла попадает в кровь с `trace_id`; по журналу сессия восстанавливается полностью.
- **G2 Заменяемость.** Смена органа-эффектора не меняет код цикла — меняется только манифест синапсов.
- **G3 Бюджет.** Лимиты задаются на трейс (параметр цикла) и на вызов (поле `budget` органа в манифесте — данные, не код). Достижение порога `alert_ratio` (по умолчанию 0.8) — событие `alert` (не более одного на трейс); превышение per-call лимита уже состоявшегося вызова — событие `alert` с именем органа; исчерпание лимита — HALT с событием `halt` (граница включена). Бюджет читается из крови (totals по trace_id), не из памяти цикла.

## Отказные режимы

| Ситуация | Поведение |
|---|---|
| Орган не отвечает (таймаут) | событие `error` → REFLECT → повтор ≤ 2 или смена органа |
| Инструмент не объявлен в манифесте | отказ на PLAN, событие `veto` |
| Кровь недоступна | цикл останавливается: без журнала действие запрещено |
| Порог бюджета достигнут | событие `alert` (один на трейс), цикл продолжается (G3) |
| Per-call лимит вызова превышен | вызов оплачен; событие `alert` с именем органа (G3) |
| Бюджет исчерпан | HALT (G3) |

## Приёмка

- [ ] Цикл завершает задачу с любым органом из манифеста без правок кода.
- [ ] Тест отключения: замена ollama ↔ llama.cpp не меняет ствол мозга.
- [ ] Полная реконструкция сессии по журналу крови.
- [ ] Ровно один `alert` при достижении порога трейс-бюджета; `alert` per-call с именем органа при превышении лимита вызова; тишина ниже порога и на включённой границе per-call (строго-больше).
- [ ] Ни одного вызова органа вне синапсов (проверяется журналом).
