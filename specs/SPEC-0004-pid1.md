# SPEC-0004: PID 1 — живой организм (сердцебиение)

Статус: принято (спека до кода) · Версия: 0.2.0 · Дата: 2026-11-03 (v0.2.0: правило тишины — W-0032, бюджет внимания человека — W-0025, зерно FR-09 пакета «Human Membrane», волна №23)
Относится к: SPEC-0001, SPEC-0002, SPEC-0003, ADR-0006

## Назначение

Режим живого организма: процесс с ритмом жизни — boot, сердцебиение, смерть. Ствол мозга (SPEC-0001) отвечает на вопрос «что делать», PID 1 — на вопрос «жив ли я»: организм существует во времени, слышит свои органы и умирает по-записанному. Доктрина ЧЕЛОВЕК=PID=1 (ADR-0006): init'ом остаётся человек — организм никогда не назначает себе вечность.

## Контракт

1. Сессия организма: `BOOT → HEARTBEAT×N → SHUTDOWN`. Все события сессии — один `trace_id` (G1 SPEC-0001).
2. **BOOT**: событие `boot` (source `pid1`): `{pid, interval, organs}`. Организм — одиночный процесс в теле: второй живой экземпляр не стартует — события `veto` + `shutdown` (причина `second_instance`), выход 1. Одиночность держит файловый lock с pid владельца и датой; протухший lock (владелец мёртв) заменяется молча.
3. **HEARTBEAT** (каждые `interval` секунд): опрос healthcheck всех органов манифеста — событие `organ.health` (source `pid1`) с `{healthy}` и замером секунд в `cost`. Недоступный орган не останавливает сердце: `healthy=false`, ритм идёт.
4. **SHUTDOWN**: событие `shutdown` с причиной и итогами сессии: `signal:SIGTERM` / `signal:SIGINT` (человек), `budget:<детали>` (G3 SPEC-0001), `max_beats`, `second_instance`. Смерть без записи запрещена: сигнал перехватывается, дети-процессы завершаются через `shutdown()` (SPEC-0002 п.7), кровь закрывается.
5. Кровь пишется на диск в момент события (append-only, `blood.jsonl` прогона), не снимком в конце: смерть процесса не теряет ни одного конверта. Сессии одного дня — в одном файле, различаются `trace_id`.
6. Отчёт сессии: при остановке пишется `report-<trace_id>.md` — реконструкция (G1), свод здоровья по органам, итог цены.
7. **Правило тишины (0.2.0, W-0032, поверх ADR-0006): молчание — записанное решение, а не вечное ожидание.** Запрос одобрения Человеку — событие `approval.request` (source `pid1`): payload `{what, question?, window_seconds, priority, expires_at, tool?}`. Окно ЗАЯВЛЕНО просящим: запроса без окна не существует, окно ≤ 0 — не грамматика (ValueError до записи, ADR-0014 — как неизвестный тип события); приоритет — из словаря внимания (п.9). Ответ — по-записанному (`brainstem/approval.py`):

   - одобрение — событие `approval.grant` с `causation_id` = id запроса и `who` (строка-заявка, доверие unverified по природе — W-0024); ключ идемпотентности `approval.grant:{request_id}` — повторное одобрение не создаёт вторую строку (A01);
   - одобрение, записанное до `expires_at`, — ответ `granted`;
   - окно истекло без одобрения — **ответ по умолчанию «нет»**: правило тишины само пишет `veto` (source `pid1`, причина «правило тишины…», `request_id`, ключ `approval.silence:{request_id}`, A01 — повторное решение возвращает ту же строку); необратимое не исполнено (A17: сохранено, не исполнено);
   - до окна — ответ `waiting`: ожидание ничего не пишет и ничего не отменяет;
   - опоздавшее одобрение (после отмены) остаётся в крови вестью (append-only) — необратимое не оживляет.

   Ожидание не останавливает дом: тишина — пауза внутри МЫ, а не вечное ожидание (инвариант 32 llms.txt) — работу дома ожидание внешнего слова не блокирует, остановлено только само необратимое действие. Наружу правило уже работало (донорский триггер тишины, окно follow-up — `runs/2026-11-03-wave17-membrane-blood/donors-sweep.md`); п.7 делает его общим — и внутрь дома.
8. **Бюджет внимания человека (0.2.0, W-0025, зерно FR-09 пакета): внимание — ресурс организма.** События, прерывающие Человека, несут в `cost.attention` заявленный расход внимания (целое ≥ 0; отсутствие = не заявлено — незаявленное не достраивается, A02; ноль не пишется — старый стиль крови жив). Словарь приоритетов — один, `brainstem.attention.ATTENTION_PRIORITIES` (копий нет): **P0** — остановка перед риском/необратимостью (спрашивает всегда — у риска нет безопасного default); **P1** — срочное существенное решение (спрашивает, только если нет безопасного default); **P2** — дневная сводка (не прерывает); **P3** — тихая запись (не прерывает). Косметические вопросы не задаются: `should_ask` — вопрос с безопасным default, который можно изменить позже, не задаётся (запись вместо вопроса). **Скрытой поведенческой телеметрии нет и не будет**: счёт внимания — только по заявленной крови (вопросы, одобрения, отказы, остановки); `metrics()` — read-only проекция, неизмеримое = UNKNOWN (None), не ноль. «Меньше вопросов не значит лучше, если растут опасные действия»: метрики показывают вопросы и необратимые действия рядом — оборотную сторону не прячут.
9. **Коды выхода:** `0` — чистая смерть (сигнал, лимит биений); `1` — не стартовал (второй экземпляр, конфигурация); `2` — бюджет исчерпан.

## Инварианты

- G1 Трассируемость: boot → каждое биение → shutdown — один trace_id; файл крови полностью реконструирует сессию.
- G4 Смерть с записью: любой управляемый путь остановки оставляет `shutdown` в крови; только SIGKILL человека молчит (и это его право).
- G5 Человек-инициатор: запуск и убийство организма — только человек. Юнит-файлы демонов и автостарт в репозиторий не входят — организм не планирует себе вечность.
- G6 Одиночность: два организма в одном теле невозможны; второй получает veto.
- G7 Тишина — записанное решение (0.2.0, W-0032): у каждого вопроса к Человеку есть заявленное окно и по-записанное поведение по умолчанию («нет»); молчание за окном отменяет необратимое событием veto от правила, вечного ожидания нет; опоздавшее одобрение необратимое не оживляет.

## Отказные режимы

| Ситуация | Поведение |
|---|---|
| Второй живой экземпляр | `veto` + `shutdown(second_instance)`, выход 1 |
| Протухший lock (владелец мёртв) | заменяется, организм стартует |
| Бюджет исчерпан | `shutdown(budget:…)`, выход 2 |
| Орган не отвечает на сердцебиение | `organ.health healthy=false`, ритм продолжается |
| Орган-процесс завис | таймаут из `timeouts` манифеста (SPEC-0002 п.7): процесс завершён, healthcheck ложь |
| Сигнал человека | `shutdown(signal:…)`, дети завершены, выход 0 |
| Запрос одобрения без окна / окно ≤ 0 | запрос не записывается — ValueError до факта (0.2.0, ADR-0014) |
| Приоритет не из словаря внимания | запрос не записывается — fail-closed (0.2.0) |
| Окно истекло без одобрения | veto от правила тишины — по умолчанию «нет» (0.2.0, W-0032); повтор — та же строка (A01) |
| Одобрение после отмены | записано вестью; необратимое не оживляет (0.2.0) |
| SIGTERM/SIGINT человека | `shutdown(signal:…)`, дети завершены, выход 0 |

## Приёмка

- [ ] Boot → N биений → Shutdown: один trace_id, все конверты валидны по схеме.
- [ ] Второй живой экземпляр получает veto и не стартует.
- [ ] Протухший lock заменяется — организм стартует.
- [ ] Остановка по сигналу: `shutdown(signal:…)`, все органы-процессы завершены через `shutdown()`.
- [ ] Кровь в файле на диске равна крови в памяти в любой момент сессии (запись в момент события).
- [ ] Бюджет → `shutdown(budget:…)`, выход 2.
- [x] Правило тишины (0.2.0, W-0032): запрос с заявленным окном/приоритетом/expires_at, без окна не записывается; одобрение до окна — granted (causation_id, A01); тишина за окном — veto от правила (повтор — та же строка, A01); опоздавшее одобрение не оживляет; pending — только безответные. Приёмки: `tests/test_wave23_silence_attention.py`, живой прогон [`runs/2026-11-03-wave23-silence-attention/`](../runs/2026-11-03-wave23-silence-attention/report.md).
- [x] Бюджет внимания (0.2.0, W-0025): словарь P0–P3 (копий нет), cost.attention (0 не пишется, totals суммируют), P0 спрашивает всегда, косметические вопросы не задаются, метрики read-only, неизмеримое = UNKNOWN. Приёмки: `tests/test_wave23_silence_attention.py`, живой прогон [`runs/2026-11-03-wave23-silence-attention/`](../runs/2026-11-03-wave23-silence-attention/report.md).
- [ ] MCP-stdio: зависший орган обнаруживается таймаутом, процесс завершается.

## Upstream-референсы

- `torvalds/linux` — семантика PID 1 (сигналы по умолчанию игнорируются, сироты собираются родителем): идея, не код.
- systemd — отклонён как зависимость: организму не нужен менеджер служб, чтобы жить под человеком.
