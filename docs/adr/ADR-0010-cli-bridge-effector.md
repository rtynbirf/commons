# ADR-0010: Мост к эффектору — CLI вместо самодельного протокола

Версия: 0.1.0 · 2026-11-02 · Статус: принято · Спека: SPEC-0008

## Контекст

openclaw — эффектор организма (руки в каналах человека). Его gateway поднимает WebSocket
управления (протокол v4: connect-фрейм, req/res/event, лимиты payload) и небольшой набор
HTTP-эндпоинтов. Документация протокола прямо говорит: клиент на другом языке не должен
собирать handshake вручную; для разовых вызовов из шелла есть `openclaw gateway call`.
Тело организма — Python без внешних зависимостей (только PyYAML/jsonschema), и его поверхность
действия обязана быть минимальной: урок CVE-2026-25253 и вредоносных навыков ClawHub.

## Решение

Мост строится на CLI: `openclaw gateway call <method> --json [--params '<json>']` —
с белым списком методов (`health`, `status`, `chat.send`, `chat.abort`), структурными
параметрами (dict, сериализуемый телом — модель не строит строки shell) и инъектируемым
runner'ом (тесты — фейк, сеть CI не трогается). Секреты — только env хоста человека; живой
gateway — PID 1.

## Альтернативы

- **WebSocket-клиент своими руками** — нарушает явную рекомендацию протокола; второй парсер
  фреймов = вторая поверхность атак; ради четырёх методов.
- **HTTP `POST /tools/invoke`** — вызывает инструменты openclaw'а под его tool policy: это
  его мир, не импульс организма; plus auth и политика — не наши гейты.
- **Встроить SDK/npm-пакет** — вендоринг органа внутрь тела, нарушает SPEC-0006.

## Последствия и проверяемость

+ Поверхность эффекта = 4 метода и один формат вызова; протокольные дрейфы openclaw не
  ломают тело (CLI — их публичный контракт совместимости).
+ Инъекция невозможна архитектурно: параметры сериализуются телом, аргументы идут списком.
− Двухпрыжковая задержка (python → CLI → gateway); для рук организма — приемлема.
− Нужен установленный CLI на хосте организма; при отсутствии — `binary-missing`, тело честно
  отказывается (fail-closed), не деградирует.

Проверяемость через полгода: белый список не вырос без правки спеки; мост не выучил ни одного
метода сверх списка; живой запуск на хосте владельца случился хотя бы раз.
