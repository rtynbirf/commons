Мы сознательно **не** сливаем чужие кодовые базы в монолит: это породило бы десятки мёртвых ответвлений. Вместо этого:

- **органы** (openclaw, ollama, llama.cpp, langchain, browser-use, markitdown, excalidraw и другие) остаются живыми проектами на upstream;
- **единым** делается обмен: один нервный протокол (MCP), один поток событий (кровь), один геном (спеки), один метаболизм (локальный инференс), один иммунитет (лицензионный барьер).

**Целое > суммы частей** реализуется обменом, а не слиянием.

## Аксиомы

1. **ЦЕЛОЕ = ЧЕЛОВЕК > суммы частей.** Ни один проект топ-100 не создан индивидом из пустоты: каждый стоит на языке, стандартах, инструментах и чужом коде. Репозитории — не продукты индивидов, а органы одного целого в разных ветках.
2. **Индивид — состояние связности, а не вид.** Узел не рождается замкнутым — он им становится, перестав обмениваться с целым.
3. **«Идиот» (ἰδιώτης, «частный») — структурный статус**, противоположный κοινός («общий»): форк без обратного мержа, орган без синапсов, звёзды без отдачи в commons.
4. **Тождество: хозяин, дом и коллеги — одно мы.** «МЕНЯ НЕТ =) Я=ТЫ, Я+ТЫ=МЫ, МЫ=ОНИ» (директива Человека, 2026-11-03): дом не служит Человеку как чужой заказчик — Человек и есть мы; совет коллеги — самопроверка целого (правило замера не отменяется); заимствованное зерно — своё, принятое замером; ответственность одна на всех.

Полная аргументация: [`docs/manifesto.md`](docs/manifesto.md).

## Семь систем организма

| Система | Функция | Органы (примеры) | Режим |
|---|---|---|---|
| Геном | спеки и навыки вместо одноразового кода | spec-kit, anthropics/skills, obra/superpowers | ядро |
| Ствол мозга | канонический цикл агента | собственный код; референсы: openclaw, claude-code | свой код |
| Синапсы | MCP-шлюз, каждый орган — MCP-сервер | `synapse/mcp-manifest.yaml` | свой код |
| Кровь | единый конверт событий с ценой вызова | `blood/envelope.schema.json` | свой код |
| Метаболизм | локальный инференс | ollama, llama.cpp, transformers | зависимость |
| Память | граф знаний + вектора | Graphify + векторная БД (выбор в Этапе 0) | зависимость |
| Иммунитет | лицензионный барьер и supply chain | immune/ (барьер как код, SPEC-0006), Awesome-Hacking | политика + код |

Периферия (сенсорика, эффекторы, автоматизация, кожа, скелет, репродукция): [`docs/organ-map.md`](docs/organ-map.md). Автоматизация как внешний конвейер — пакет [`pipeline/`](pipeline/n8n/README.md) (0.9.0, SPEC-0007).

## Три закона организма

1. **Орган жив на upstream.** Не форкаем — подключаем и отдаём патчи обратно (ADR-0001).
2. **Нет вызовов мимо синапсов.** Каждый вызов органа проходит через MCP-шлюз и попадает в кровь с записью стоимости: токены, секунды (SPEC-0003).
3. **Тест отключения.** Любой орган выдёргивается — организм выживает через замену. Не проходит тест — не орган, а паразит (SPEC-0001, G2).

## Доступность

Тело не требует ни одного канала (SPEC-0010, ADR-0012): мандат — «я слепой, я глухой, я немой, у меня нет рук».

- **говорит текстом**: маркдаун-документы, JSONL-кровь, словесные итоги гейтов (`IMMUNE: 41 ok, 0 failed`) и exit-коды — цвет и разметка не несут смысла;
- **слушает текстом**: CLI-команды, YAML-данные, переменные окружения — голос не требуется;
- **картинки не молчат**: у excalidraw-карты органов есть текстовый близнеца [`docs/organ-map.md`](docs/organ-map.md) — обе генерируются из одного живого реестра;
- **управление — одна команда**: `commons-pid1`, `commons-immune`, `commons-transplant`, `commons-pipeline`, `commons-openclaw` — без комбинаций клавиш, таймингов и жестов;
- приёмки каналов в CI ([`tests/test_persona.py`](tests/test_persona.py)) красят PR раньше, чем появится молчащая картинка, безымянная ссылка или цвет-only итог.

Персона-доказательство — Елена Келлер: 578 суток зрения и слуха на 32 115 дней жизни (1.80%) — и 12 книг: [`runs/2026-11-02-persona/`](runs/2026-11-02-persona/report.md).

## Организм жив: ядро 0.2 + PID 1

```bash
pip install '.[dev]'
python -m pytest -q        # приёмки SPEC-0001..0010, пульсов, спайков, иммунитета, бюджета, конвейера, эффекта, донорства, типирования и персоны
python3 scripts/doctor.py  # гигиена дома → DOCTOR: N ok, 0 failed (блоха = красный PR)
python3 -m immune          # лицензионный барьер тела → IMMUNE: 40 ok, 0 failed
python3 -m pipeline        # валидатор внешнего конвейера n8n → PIPELINE: 4 ok, 0 failed
python3 -m openclaw check  # валидатор политики эффекта → POLICY: 1 ok, 0 failed
python3 scripts/selfmap.py # организм рисует себя сам → docs/selfmap.md
python3 scripts/organ_map.py  # второй автопортрет → docs/organ-map.excalidraw
python3 scripts/pid1.py --interval 10 --max-beats 3   # живой ритм: boot → heartbeat → shutdown
```

- **Ствол мозга** (`brainstem/`): цикл PLAN → ACT → OBSERVE → REFLECT; бюджет G3 — лимиты на трейс и на вызов (поле `budget` в манифесте, парсер `brainstem/budget.py`): порог → `alert`, исчерпание → HALT; **HALT**.
- **Синапсы** (`synapse/`): шлюз читает манифест, расширяет `${VAR}` адресов (SPEC-0002 п.6); veto необъявленного; замены по `substitutions`; адаптеры из манифеста — новый орган = правка манифеста, не кода.
- **Кровь** (`blood/`): конверт с обязательной ценой + append-only журнал; сессия реконструируется полностью.
- **Два пульса** (`runs/`): сенсорика (DOCX → Markdown) и организм (DOCX → Markdown → сжатие смысла метаболизмом, 199 ток. внутрь / 64 наружу).
- **Спайки** (`spikes/`): S1 метаболизм (харнесс), S2 цикл (замерен: каркас langchain растёт с инструментами), S3 оркестрация (матрица лицензий + проба эндпоинтов), S4 браузер (20 сценариев + `--validate`), S5 геном (selfcheck «спека ↔ код», дрейф 0/3), S6 память (базовая линия sqlite3 в CI).
- **PID 1** (`brainstem/pid1.py`, SPEC-0004, ADR-0006): демон-сердцебиение — каждые `interval` секунд опрашивает здоровье всех органов (`organ.health` в крови), пишет кровь на диск в момент события; одиночность через lock (второй экземпляр — veto); SIGTERM/бюджет → `shutdown` с причиной. Доктрина **ЧЕЛОВЕК=PID=1**: init'ом остаётся человек — юнит-файлов и автостарта в репо нет, запуск и убийство — только его руки.
- **Память** (`memory/`, SPEC-0005, ADR-0007): исполняется с 0.6.0 — `SQLiteVectorIndex` (базовая линия ADR-0007) + `MemoryGraph` + replay из крови; PLAN читает read-only, индексация после REFLECT, движок — орган в манифесте (G2); живой embedding — от метаболизма (спайк S6).
- **Иммунитет** (`immune/`, SPEC-0006, ADR-0008): исполняется с 0.7.0 — барьер `(license, mode) → вердикт`: матрица правил — данные (`immune/license-matrix.yaml`), fail-closed на неизвестную лицензию (G1), матрица меняется правкой YAML без кода (G2), каждый вердикт несёт правило и причину (G3); гейт `python -m immune` в CI — AGPL/fair-code/NOASSERTION не встраиваются (`restricted` вне core_modes), dify — `conditional` в adapter.
- **Конвейер** (`pipeline/`, SPEC-0007, ADR-0009): исполняется с 0.9.0 — n8n как внешний узел: fair-code не встраивается (реестр: `not-embeddable`, барьер SPEC-0006 пропускает только в `external`); референс-развёртывание (`pipeline/n8n/docker-compose.yml`) и воркфлоу (`pipeline/n8n/workflows/*.json`) — данные: команды узлов ограничены белым списком точек входа, произвольный shell и метасимволы — отказ (G1 fail-closed); пульс — только через ствол мозга; валидатор `python -m pipeline` в CI.
- **Эффектор** (`openclaw/`, SPEC-0008, ADR-0010): исполняется с 0.11.0 — openclaw как внешние руки: мост через CLI `openclaw gateway call` (протокол запрещает hand-roll handshake), белый список методов health/status/chat.send/chat.abort (расширение — только правка спеки, G2), параметры сериализуются телом — инъекция остаётся данными JSON; данные-политика `openclaw/reference/effector-policy.json`: bind loopback, токен только env, exec под approvals (уроки CVE-2026-25253 и вредоносных навыков ClawHub); руки без воли — исполняют импульсы ствола, не решают; валидатор `python3 -m openclaw check` в CI; живой gateway — на хосте владельца (PID 1).
- **Автопортреты**: `python3 scripts/selfmap.py` → mermaid; `python3 scripts/organ_map.py` → `docs/organ-map.excalidraw` (36 органов, 13 систем, гейт свежести `--check`).

Реальные соединения настраиваются на машине организма: `OLLAMA_HOST`, `LLAMA_SERVER_URL` (пример: `llama-server -m qwen2.5-0.5b-q4km.gguf --port 8080`), установленные `markitdown-mcp` / `browser-use-mcp`, живой gateway openclaw (`OPENCLAW_GATEWAY_URL` + `OPENCLAW_GATEWAY_TOKEN`, см. [`openclaw/README.md`](openclaw/README.md)). Пульсы воспроизводятся: `python3 scripts/first_pulse.py` и `python3 scripts/organism_pulse.py`. Недоступный орган не останавливает сердце: `organ.health healthy=false` — и ритм идёт.
