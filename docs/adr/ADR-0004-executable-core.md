# ADR-0004: Исполнимое ядро 0.2 — код следует за спекой

Статус: принято · Дата: 2026-11-01
Supersedes: частично ADR-0003 по объёму (Apache-2.0 остаётся без изменений)

## Контекст

0.1.x — blueprint: геном (спеки), реестры, провенанс. DoD M1 требует «простейший агент
выполняет одно полезное действие целиком через синапсы, полный трейс из журнала крови,
ни одного события с пустой cost». Значит ядро должно исполняться, оставаясь органом-агностиком.

## Решение

Ядро — Python-пакет `commons-organism` внутри анатомических папок репозитория:

- `blood/` — конверт (валидация по JSON Schema, draft 2020-12) + append-only журнал (SPEC-0003);
- `synapse/` — шлюз: манифест как источник истины, veto, замены, динамическая загрузка
  адаптеров по полю `adapter` (SPEC-0002); адаптеры: ollama (HTTP), llama.cpp (HTTP),
  универсальный MCP-stdio (markitdown, browser-use и будущие органы);
- `brainstem/` — канонический цикл PLAN→ACT→OBSERVE→REFLECT с бюджетом G3 (SPEC-0001);
- `tests/` — 26 приёмок спек в форме pytest: G1 реконструкция, G2 тест отключения,
  G3 бюджет, второй закон (нет вызовов мимо синапсов), veto, security.violation.

Бюджет читается из крови (журнала), а не из памяти цикла: кровь — источник истины.
Рефлексия M1 — детерминированная (намерение = вызов вернул результат); LLM-рефлексия
приходит с метаболизмом и не меняет контракт цикла.

## Альтернативы

- Монорепо с реальными зависимостями органов (pip-пакеты browser-use/transformers) — отклонено:
  нарушает ADR-0001 (органы остаются на upstream), утяжеляет CI, лишает теста отключения.
- Внешний оркестратор (langchain/n8n) в роли ствола мозга — отклонено: SPEC-0001 требует
  единственный цикл; сравнение зафиксировано спайком S2, а не верой.
- Bash-скрипты вместо пакета — отклонено: тесты, типы и бюджет требуют нормальной среды.

## Последствия

**Положительные:** приёмки спек исполняются в CI; новый орган одного класса транспортов
подключается правкой манифеста; DoD M1 проверяем механически.
**Отрицательные / цена:** репо больше не docs-only — нужен мейнтейнинг кода и его SECURITY;
pytest и зависимости в CI; обязательство SemVer для пакета.
**Обратный мерж:** находки о работе MCP-stdio отправляются в upstream markitdown/browser-use.

## Проверяемость

- CI зелёный на 26 приёмках — база.
- G2 измеримо: замена ollama ↔ llama.cpp на живой машине за минуты правкой манифеста (спайк S1).
- S2 покажет, остаётся ли собственный цикл дешевле по токенам при равной трассируемости.
