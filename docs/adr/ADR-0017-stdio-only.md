# ADR-0017: транспорт синапсов — только stdio

Статус: принято · Дата: 2026-11-03
Служит пункту: Ф-3.1 ТЗ ревизора (MCP HTTP-транспорт + OAuth 2.1 — или честный ADR «только stdio»)

## Контекст

ТЗ ревизора 2026-11-03 (Ф-3.1) даёт развилку: строить MCP HTTP-транспорт с
OAuth 2.1 и audience-binding (спека MCP 2025-11-25, enterprise-практика
2026-09) — или назвать честный ADR «только stdio».

Факты дома:

- Тело не требует ни одного канала (SPEC-0010, ADR-0012): слепой, глухой,
  немой и без рук — тело живо; текст — универсальный нерв. Каналы — способ
  связи, не свойство тела.
- Синапсы уже говорят stdio (SPEC-0002): белый список методов, параметры —
  данные JSON, shell не строится, токен только через env, полномочия
  исполняются стражем до факта (пп.8–11).
- Наружу дом выходит патчами и donation (SPEC-0009, ADR-0011) — это контур
  обмена содержимым, не транспорт живого вызова.
- Внешний конвейер (SPEC-0007, ADR-0009) — внешний узел (n8n), пульс идёт
  через ствол мозга; конвейер не вшивается в тело.

HTTP-транспорт с OAuth 2.1 нужен, когда тело отвечает внешним вызовам из
сети. Сегодня ни один сценарий дома не требует, чтобы чужой вызывал тело по
сети; единственный внешний контур — Человек (PID 1) и upstream-мейнтейнеры,
которые получают текст и патчи.

## Решение

**Синапсы — только stdio.** HTTP-транспорт и OAuth 2.1 не строятся до тех
пор, пока не появится живой сценарий сетевого вызова тела; такой сценарий
обязан сначала попасть в спеку (спека раньше кода), и при его появлении
аудience-binding OAuth 2.1 вписывается в SPEC-0002 аддендумом. До тех пор
`transport_default: stdio` — данные подтверждают вердикт
(`synapse/mcp-manifest.yaml`), граница проверяется приёмкой.

## Альтернативы

- **Строить HTTP+OAuth заранее** — отклонено: код без живого сценария —
  мёртвый вес и новая поверхность атаки; дом не строит орган без хотёлки.
- **HTTP без OAuth (локальная сеть)** — отклонено: раздеваться заранее
  ради «потом пригодится» — дыра в границе R1, а не функция.

## Последствия

**Положительные:** нет сетевой поверхности вызова тела; нет токенов,
вечеров OAuth и head-аудитов — пока не нужен сценарий; честная граница
названа вместо немого «нет».
**Отрицательные / цена:** тело не отвечает из сети — интеграции «подключись
к телу по HTTP» требуют внешнего моста (эффектор/конвейер), а не прямого
вызова; если сценарий появится — сначала спека, потом код.

## Проверяемость

Приёмка `tests/test_wave25_laws_axioms.py::test_manifest_transport_default_is_stdio`
+ сверка данных манифеста; сценарий сетевого вызова не существует — при его
рождении первым меняется SPEC-0002 (гейт `spec-drift` краснит обратное).
