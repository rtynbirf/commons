# Отчёт волны №20 — верификация советов коллег (внешний аудит 2026-11-03)

ТОЛЬКО ЗА НАМИ».

## Что служено

Коллеги прислали пакет: аудит (12 находок F-01…F-12 с репро-пробами), ревизию
заявлений, арбитраж (6 решений D1–D6) и патч (2 закрытия + 6 приёмок). Правило
дома: **совет — не факт, факт — замер на живом коде**. Все четыре их пробы
прогнаны на живом HEAD 0.38.0 **до** правок — все воспроизводимые находки
подтвердились один в один (кровь волны, конверт `verify-colleague-probes`):

- **F-01** подмена содержимого при сохранённых `id`/`prev_id` проходит
  `verify` (chained=True), усечение хвоста тоже;
- **F-02** несериализуемый payload — конверт в памяти без строки в файле,
  якорь `prev_id` рассинхрон;
- **F-03** эффект без крови — орган вызван, `act` не записан, TypeError
  вылетел из `run()` без halt;
- **F-04** `os.truncate` обнулил файл при `fs: read-only`; symlink/link/utime
  не прерваны;
- **F-05** `listdir`/`scandir`/`stat` прошли при `fs: none`;
- **F-06** `{"error":…, "ok": false}` от органа — `satisfied=True`;
- **F-07** бюджет 1000/10 последним шагом — `run()=True` без halt.

### Принято в дом (спека раньше кода, своими руками — не чужим патчем)

| Находка | Решение | Где |
|---|---|---|
| F-02 | **SPEC-0003 v0.11.0 п.14**: кровь не принимает несериализуемое — `append` сериализует ДО мутации, `EnvelopeError`, отказ записи ничего не меняет (ни строки, ни памяти, ни цепочки) | `blood/journal.py` |
| F-04 | **SPEC-0002 v0.11.0 п.8**: полная грамматика мутаций — `truncate`/`symlink`/`link`/`utime`/`setxattr`/`removexattr`; `link` — оба конца, `symlink` — создаваемая ссылка | `synapse/authority.py` |
| F-05 | `listdir`/`scandir` при `fs: none` — прерваны (кроме рантайма Python), при скоупе — только внутри корней (realpath) | `synapse/authority.py` |
| F-03 | Проверка ДО факта: Loop сериализует payload шага до invoke — эффект не случается без крови; `BloodRecordError` в шлюзе — эффект без крови назван error-конвертом и завершает трейс halt (G1) | `brainstem/loop.py`, `synapse/gateway.py` |
| F-01 | **Граница названа честно** (не прикрыта): докстринг журнала — «цепочка шьёт порядок, а не байты»; приёмка-документация границы в сюите; защита содержимого — хотёлка **W-0026** (`prev_sha256` + внешний якорь) | `blood/journal.py`, SPEC-0003 п.14 |

Честные границы, названные фактом промера (audit-событий в CPython **нет**):
`os.stat`, `os.mkfifo`, `os.mknod` — страж принципиально слеп к ним; страж —
in-process сигнализация, не граница против враждебного кода (ctypes/нативный
код — за ядерной песочницей детёнышей, п.11). Всё вписано в SPEC-0002 п.8.

### Хотёлки-зерна (с хозяевами, гейт `wants` доволен)

- **W-0026** — кровь, заверенная от подделки: `prev_sha256` (аддитивно, кровь
  валидна навсегда) + внешний якорь против усечения хвоста (F-01/D1);
- **W-0027** — REFLECT по проверяемому критерию: `Step.accept` (JSON-схема или
  предикат); независимый проверяющий — потом, как орган за синапсом (F-06/D2);
- **W-0028** — А/Б против разумной базы Б2: «диспетчер, который инженер
  напишет за час» (F-08/D5);
- **W-0029** — бюджет останавливает и после последнего шага (F-07);
- **W-0030** — гейт «поведение без спеки» в doctor (F-09/D3);
- **W-0031** — PIDLock против зомби-владельца: гипотеза, проверить живьём (F-12).

### Отклонено/отложено с причиной (решение — за Человеком)

- **D6** «README ≤ 60 строк»: README дома — журнал, а не витрина; резать без
  слова Человека не будем — решение за ним.
- **Adversarial Verifier как особая роль ствола**: закон 2 — проверки идут
  через синапсы; верификатор — орган, не роль ствола; сначала W-0027.

## Урок волны

Патч коллег был правильный, но дома его не применили бы `git apply`: у нас
другая дисциплина (спека раньше кода, приёмки с именами, докстринги по духу).
Советы приняты **по существу и по духу**: замер → вердикт → своя реализация →
свои приёмки. Чужая работа сэкономила разведку — это и есть commons.
