# SPEC-0001: Ствол мозга — канонический цикл агента

Статус: принято (спека до кода) · Версия: 0.6.0 · Дата: 2026-11-03 (v0.2.0: G3 алерты и per-call лимиты из манифеста — M3; v0.3.0: REFLECT по проверяемому критерию — Step.accept — хотёлка W-0027, зерно коллег F-06/D2, волна №21; v0.4.0: бюджет проверяется и после шага — хотёлка W-0029, зерно коллег F-07, волна №22; там же — обратимость честным языком: класс на шаге, одобрение до необратимого, компенсация как отдельная операция — хотёлка W-0024, зерно FR-05/FR-06 и ADR-002 пакета «Human Membrane»; v0.5.0: п.7 — одобрение живьём, правило тишины — Step.approval_window, контур approval.* — хотёлка W-0032, волна №23; v0.6.0: п.8 — внешний аварийный стоп петли — хотёлка W-0033, дыра ревизии 2026-11-03; G3 дополнен четвёртым ресурсом — внимание Человека — хотёлка W-0025, зерно FR-09 пакета, волна №24)
Относится к: ADR-0001, ADR-0002, SPEC-0002, SPEC-0003

## Назначение

Единственный источник агентного цикла в организме. Эффекторы и референсы (openclaw, claude-code, opencode) изучаются, но цикл реализуется один раз — здесь. Никакой орган не решает сам, что делать организму.

## Контракт

Цикл: `PLAN → ACT → OBSERVE → REFLECT → (PLAN | HALT)`.

1. **PLAN**: выбор следующего действия только из инструментов, объявленных в `synapse/mcp-manifest.yaml`. Инструмента нет в манифесте — действия нет (событие `veto`).
2. **ACT**: вызов органа строго через MCP-шлюз (ADR-0002). Прямые вызовы органов запрещены.
3. **OBSERVE**: результат нормализуется в конверт крови (SPEC-0003) с заполненной `cost`.
4. **REFLECT**: сравнение результата с намерением; событие `reflect`; решение — новый PLAN или HALT. Сравнение — по проверяемому критерию (0.3.0, W-0027): шаг плана может объявить `Step.accept` — JSON-схему результата или предикат; рефлексия меряет результат им и в `reflect` называет критерий (`criterion`: jsonschema/predicate/m1) — читатель крови видит, чем мерилось, а не только вердикт. Критерий не объявлен — прежняя рефлексия M1 (результат есть — удовлетворено), аддитивно: старые планы валидны. Упавший предикат и непонятный критерий — дефект плана: намерение не удовлетворено, причина названа, трейс завершён halt (G1).
5. **Обратимость и одобрение до факта (0.4.0, W-0024, зерно FR-05/FR-06 пакета)**: шаг плана заявляет класс обратимости ДО факта — `Step.reversibility` из словаря пакета (`reversible` / `compensatable` / `partially_reversible` / `irreversible` / `unknown`; словарь — в `blood.envelope.REVERSIBILITY_CLASSES`, копий нет); заявка пишется в план и переносится шлюзом в акт (SPEC-0003 п.16). Не заявлено — поле нет: старые планы валидны (аддитивно), дневник честно называет незаявленное. **Класс не из словаря — дефект плана: halt до факта** (fail-closed, ADR-0014: опечатка не должна молча значить «unknown»). **Необратимое без одобрения не исполняется**: `Step.reversibility == "irreversible"` без `Step.approval` (строка-заявка «кто одобрил», доверие unverified по природе) — событие `veto` до факта + halt (G1); акта в крови нет, орган не вызван. «Спрашивать» для ствола — остановиться и назвать, чего не хватает: решение — за Человеком (PID 1), не за циклом.
6. **Компенсация — новая операция, не редактирование прошлого (0.4.0, W-0024, зерно ADR-002 пакета — Saga)**: `brainstem/compensator.py` — отмена ничего не вычёркивает из крови (append-only, SPEC-0003 п.4): компенсация — отдельный трейс с `causation_id` = id отменяемого акта (честное происхождение, SPEC-0003 п.10) и идемпотентным ключом `compensate:{act_id}` (A01, SPEC-0003 п.9: повторная компенсация не создаёт вторую строку акта). Компенсатор объявляется манифестом органа — `compensators: {инструмент: инструмент отмены}` (данные, не код — G2); инструмент отмены получает payload исходного акта. **Проверка состояния после обязательна**: без критерия приёмки (`Step.accept`-грамматика, W-0027) компенсация не запускается — «результат есть» ≠ «отменено». Вердикты словаря пакета: `COMPENSATED` / `COMPENSATION_PARTIAL` / `NOT_REVERSIBLE`; частичная компенсация — не PASS: `satisfied=false`, трейс закрыт halt (G1); частичность заявляет сам орган в результате (`"compensation": "partial"`) — дом не догадывается. **Необратимое честно не отменяется**: класс акта `irreversible` или компенсатор не объявлен — вердикт `NOT_REVERSIBLE`, попытки не было (сохранено, не исполнено — A17). Критерий меряет отчёт органа о состоянии после — дом читает отчёт, не лезет в чужой орган за синапсами.
7. **Одобрение живьём — правило тишины (0.5.0, W-0032, SPEC-0004 п.8)**: шаг может объявить `Step.approval_window` — тогда перед ACT ствол пишет `approval.requested` и ждёт ответа Человека в окне (канал одобрения подключается конструктору цикла): `approval.granted` — шаг исполняется; `approval.veto` — намерение не удовлетворено, трейс завершён halt (G1); `approval.expired` — тишина = «нет» по-записанному, до органа шаг не доходит (`act` отсутствует). Когда окно объявлено, вето п.5 «необратимое без одобрения» откладывается до вердикта контура — спрашивать по-настоящему лучше, чем остановиться от отсутствия нерва; воля Человека в крови — источником pid1, отличима от воли тела. Канал не подключён при объявленном окне — fail-closed: `error` + halt без притворного ожидания. Окно <= 0 — дефект плана: ValueError до первой записи (правило без окна — не правило).
8. **Внешний аварийный стоп петли (0.6.0, W-0033, дыра ревизии 2026-11-03)**: трейс можно остановить снаружи, между шагами, — не дожидаясь вердикта его собственной рефлексии (а рефлексия M1 — тахометр, находка F-06). Ствол принимает `stop_check` конструктором — вызываемый без аргументов, возвращает `None` (тишина — живём) или причину-строку (стоп). Проверка — на верху каждой итерации, до бюджета и до плана, **и сразу после каждого шага** (после рефлексии, до бюджет-хвоста W-0029 — стоп старше бюджета и здесь): стоп, поданный во время шага — в том числе последнего, — закрывает трейс на его границе halt'ом, не проходом, и не игнорируется молча. **Аварийный стоп старше бюджета и старше вопроса** — остановленный трейс не тратит ни токенов, ни внимания Человека на косметические шаги. Пришедший стоп пишется в кровь честным контуром: `stop.requested` (source `pid1` — по ADR-0006 организм останавливает только Человек, воля отличима от воли тела источником; причина, шаг, внимание 1 с классом P0 — остановка перед риском) → `reflect` (намерение не удовлетворено) → `halt` (G1). Сломанный нерв не управляет волей: канал упал или вернул нечитаемое — `error`-конверт (стоп-сигнал не приписывается Человеку — source остаётся `brainstem`), тело останавливается и называет, чего не хватает; `run() = False`. Честные границы: стоп действует на границе шагов — живой вызов органа договаривает (эффект уже случился, он назван в крови), открытое окно тишины (п.7) договаривается до вердикта — G7 не взламывается; мгновенная остановка процесса — уровень ОС, право Человека (SPEC-0004 G4/G5), в крови видна постфактум. Стоп-канал не удаляет и не правит ничего: он читает — текст как универсальный нерв (SPEC-0010).

## Гарантии

- **G1 Трассируемость.** Каждый переход цикла попадает в кровь с `trace_id`; по журналу сессия восстанавливается полностью.
- **G2 Заменяемость.** Смена органа-эффектора не меняет код цикла — меняется только манифест синапсов.
- **G3 Бюджет.** Лимиты задаются на трейс (параметр цикла) и на вызов (поле `budget` органа в манифесте — данные, не код). Достижение порога `alert_ratio` (по умолчанию 0.8) — событие `alert` (не более одного на трейс); превышение per-call лимита уже состоявшегося вызова — событие `alert` с именем органа; исчерпание лимита — HALT с событием `halt` (граница включена). Бюджет читается из крови (totals по trace_id), не из памяти цикла. Проверка до шага **и после шага** (0.4.0, W-0029, зерно коллег F-07): перерасход последним шагом не проходит молча — трейс завершён halt, а не проходом (`run() = False`). **Внимание — четвёртый ресурс бюджета (0.6.0, W-0025, зерно FR-09 пакета):** `Budget.attention` — лимит обращений к вниманию Человека на трейс (вопросы, окна ожидания, аварийные стопы — всё, что кровь сосчитала по фактам, SPEC-0003 п.17); исчерпание — halt до следующего вопроса: уставший от вопросов Человек не получает ещё одного косметического. Органы в бюджете внимания не участвуют — орган не тратит внимание Человека, его тратит контур дома (SPEC-0004 п.9).

## Отказные режимы

| Ситуация | Поведение |
|---|---|
| Орган не отвечает (таймаут) | событие `error` → REFLECT → повтор ≤ 2 или смена органа |
| Инструмент не объявлен в манифесте | отказ на PLAN, событие `veto` |
| Кровь недоступна | цикл останавливается: без журнала действие запрещено |
| Порог бюджета достигнут | событие `alert` (один на трейс), цикл продолжается (G3) |
| Per-call лимит вызова превышен | вызов оплачен; событие `alert` с именем органа (G3) |
| Бюджет исчерпан | HALT (G3) |
| Бюджет исчерпан последним шагом | HALT после шага (G3, 0.4.0, W-0029): трейс завершён halt, не проходом |
| Класс обратимости не из словаря | HALT до факта (0.4.0, W-0024): дефект плана, акта нет |
| Необратимое без одобрения | `veto` до факта + HALT (0.4.0, W-0024): орган не вызван |
| Компенсатор не объявлен / класс акта irreversible | вердикт `NOT_REVERSIBLE`, попытки отмены не было (0.4.0, W-0024) |
| Частичная компенсация | вердикт `COMPENSATION_PARTIAL`, satisfied=false, трейс закрыт halt (0.4.0, W-0024) |
| Стоп-сигнал подан между шагами | `stop.requested` (source pid1) + halt на границе шагов (0.6.0, W-0033): живой вызов договаривает, следующий не планируется |
| Стоп-канал упал или вернул нечитаемое | `error`-конверт + halt (0.6.0, W-0033): воля не приписана, тело остановилось и назвало |
| Бюджет внимания исчерпан | HALT до следующего вопроса (0.6.0, W-0025, G3): косметического вопроса нет |
