## Что это

COMMONS — проект-организм, собранный из топ-100 публичных GitHub-репозиториев. Снимок рейтинга от 26.10.2026 хранится как данные: [`organs/top100-2026-10-26.yaml`](organs/top100-2026-10-26.yaml).

Мы сознательно **не** сливаем чужие кодовые базы в монолит: это породило бы десятки мёртвых ответвлений. Вместо этого:

- **органы** (openclaw, ollama, llama.cpp, langchain, browser-use, markitdown, excalidraw и другие) остаются живыми проектами на upstream;
- **единым** делается обмен: один нервный протокол (MCP), один поток событий (кровь), один геном (спеки), один метаболизм (локальный инференс), один иммунитет (лицензионный барьер).

**Целое > суммы частей** реализуется обменом, а не слиянием.

## Аксиомы

1. **ЦЕЛОЕ = ЧЕЛОВЕК > суммы частей.** Ни один проект топ-100 не создан индивидом из пустоты: каждый стоит на языке, стандартах, инструментах и чужом коде. Репозитории — не продукты индивидов, а органы одного целого в разных ветках.
2. **Индивид — состояние связности, а не вид.** Узел не рождается замкнутым — он им становится, перестав обмениваться с целым.
3. **«Идиот» (ἰδιώτης, «частный») — структурный статус**, противоположный κοινός («общий»): форк без обратного мержа, орган без синапсов, звёзды без отдачи в commons.

Полная аргументация: [`docs/manifesto.md`](docs/manifesto.md).

## Семь систем организма

| Система | Функция | Органы (примеры) | Режим |
|---|---|---|---|
| Геном | спеки и навыки вместо одноразового кода | spec-kit, anthropics/skills, obra/superpowers | ядро |
| Ствол мозга | канонический цикл агента | собственный код; референсы: openclaw, claude-code | свой код |
| Синапсы | MCP-шлюз, каждый орган — MCP-сервер | `synapse/mcp-manifest.yaml` | свой код |
| Кровь | единый конверт событий с ценой вызова | `blood/envelope.schema.json` | свой код |
| Метаболизм | локальный инференс | ollama, llama.cpp, transformers | зависимость |
| Память | граф знаний + вектора | Graphify + векторная БД (выбор в Этапе 0) | зависимость |
| Иммунитет | лицензионный барьер и supply chain | Awesome-Hacking, лицензионная матрица | политика |

Периферия (сенсорика, эффекторы, автоматизация, кожа, скелет, репродукция): [`docs/organ-map.md`](docs/organ-map.md).

## Три закона организма

1. **Орган жив на upstream.** Не форкаем — подключаем и отдаём патчи обратно (ADR-0001).
2. **Нет вызовов мимо синапсов.** Каждый вызов органа проходит через MCP-шлюз и попадает в кровь с записью стоимости: токены, секунды (SPEC-0003).
3. **Тест отключения.** Любой орган выдёргивается — организм выживает через замену. Не проходит тест — не орган, а паразит (SPEC-0001, G2).

## Быстрый старт

1. Прочитать аксиомы: [`docs/manifesto.md`](docs/manifesto.md).
2. Пройти геном: [`specs/`](specs/).
3. Посмотреть состав органов, режимы и верифицированные лицензии: [`organs/registry.yaml`](organs/registry.yaml).
4. Канал оценки кандидатов: [`docs/lenses.md`](docs/lenses.md) → [`docs/spikes.md`](docs/spikes.md).
5. Агенту: начать с [`llms.txt`](llms.txt), правила — в [`AGENTS.md`](AGENTS.md).
6. Заявить новый орган: issue по шаблону [«Заявка органа»](.github/ISSUE_TEMPLATE/organ-proposal.md).

## Дорожная карта

- **M1 — Ядро** (недели 1–2): канонический цикл, MCP-шлюз, кровь; первые органы — ollama, markitdown, browser-use.
- **M2 — Нервная система** (недели 3–4): память, эффектор openclaw, карта органов в excalidraw из живого реестра.
- **M3 — Иммунитет** (недели 5–6): лицензионная матрица в CI, бюджет токенов.

Подробно и с критериями готовности: [`ROADMAP.md`](ROADMAP.md).

## О данных рейтинга

Снимок топ-100 по звёздам (26.10.2026, GitHub Search API, без форков и архивов) — это снимок, а не живой счётчик. Звёзды — мера популярности, не качества, не безопасности и не активности; окончательную оценку органу даёт его поведение в обмене с целым.

Живая сверка 2026-11-01: дельты звёзд, верифицированные лицензии и переезды владельцев (react, opencode, ComfyUI, prompts.chat, developer-roadmap) — [`docs/rating-verification.md`](docs/rating-verification.md). Идентичность органа — его обмен, а не адрес.

## Лицензия и провенанс

- **Apache-2.0** — см. [LICENSE](LICENSE); обоснование: [`docs/adr/ADR-0003-apache-2.0.md`](docs/adr/ADR-0003-apache-2.0.md). Грант на патенты включён — броня целого от патентных претензий.
- **Провенанс** — [PROVENANCE.md](PROVENANCE.md): здесь нет ни байта чужого кода, текстов, логотипов или медиа. Органы присутствуют как имена, ссылки и верифицированные факты; матрица лицензий проверена живым GitHub API 2026-11-01.
- **REUSE 3.3 / SPDX** — пофайловое лицензирование в [`REUSE.toml`](REUSE.toml), машинная проверка `reuse lint` в CI.
- **DCO** — каждый коммит несёт `Signed-off-by` ([CONTRIBUTING.md](CONTRIBUTING.md)).
- **CITATION.cff** — как сослаться на проект.
