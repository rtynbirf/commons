# Орган: ollama/ollama

Система: метаболизм · Режим: dependency · Лицензия: MIT (верифицировано GitHub API 2026-11-01)
Статус: m1-адаптер готов — соединение настраивается `OLLAMA_HOST` на машине организма

## Роль в обмене

Локальный инференс: организм думает своим метаболизмом, не отправляя мысли наружу.
Первый орган, объявленный в манифесте синапсов; запас — llama.cpp (тест отключения).

## Контракт через синапсы

- Вход: `generate` (модель + промпт), `chat` (модель + сообщения), `embeddings` (модель + текст), `list_models`.
- Выход: ответ модели / вектор / список моделей — нормализуются в конверт крови.
- Полномочия: `network: localhost-only`, `fs: none` — орган не видит ничего, кроме своего HTTP-порта.
- Цена: `tokens_in` ← `prompt_eval_count`, `tokens_out` ← `eval_count`, `seconds` — замер шлюза.

## Адаптер

`synapse/adapters/ollama.py:OllamaAdapter` — подключён полем `adapter` в манифесте.
Healthcheck: `GET /api/tags`, таймаут 2 с. Не отвечает → замена из таблицы `substitutions`.

## Тест отключения

Замена: `llama.cpp` (тот же контракт инструментов в шлюзе, другой адаптер). Время замены: минуты — правка манифеста, цикл и код не меняются (G2, SPEC-0001).

## Обратный поток

Багрепорты и патчи — в трекер https://github.com/ollama/ollama. Форк запрещён (ADR-0001).
