# SPEC-0003: Кровь — конверт событий

Статус: принято (спека до кода) · Версия: 0.8.0 · Дата: 2026-11-03 (v0.4.0: п.6 гематология — пролитая кровь валидна навсегда; v0.5.0: п.7 цепочка `prev_id` — разрыв журнала обнаруживается при чтении, п.8 реконструкция сессии — resume из крови; v0.6.0: п.9 идемпотентность — A01 матрицы пакета Human Membrane, волны №15–№16: спека догнала живой код стыка волн; v0.7.0: п.10 честное происхождение — тройное время, причинность, классы доверия и приватности — Ф-1.1 ТЗ ревизии, волна №17 такт 1; v0.8.0: п.11 адаптер чужого контракта и конвенции чтения — такт 2 волны №17, A02/A17)
Относится к: SPEC-0001, SPEC-0002, `blood/envelope.schema.json`, `blood/adapter.py`, `blood/provenance.py`

## Назначение

Единый поток событий организма. Один журнал отвечает на вопрос «что ты сделал и чего это стоило» — всегда, для людей и для агентов.

## Контракт

1. Форма события — JSON по `blood/envelope.schema.json` (draft 2020-12).
2. Обязательные поля: `id` (UUID), `ts` (UTC), `type`, `source`, `organ`, `trace_id`, `payload`, `cost`.
3. `cost` обязателен всегда: `tokens_in`, `tokens_out`, `seconds` (ноль там, где не применимо). **Событие без цены недействительно.**
4. Журнал append-only: переупорядочивание и удаление запрещены.
5. Эмитенты: ствол мозга (каждый переход цикла), синапсы (каждый вызов), органы (значимые события — через шлюз), pid1 (boot, сердцебиение `organ.health`, shutdown — SPEC-0004).
6. **Гематология (0.4.0): пролитая кровь — часть тела.** Всё, что однажды записано под `runs/**/blood.jsonl`, остаётся валидным навсегда; приёмка гематологии (`tests/test_hematology.py`) перечитывает в CI всю пролитую кровь по схеме: полная цена каждого события, время не откатывается (append-only), сессии различимы по `trace_id`, id событий не повторяются. Спека тоже сдаёт свою кровь: пример конверта и словарь типов SPEC-0003 сверяются со схемой.
7. **Цепочка `prev_id` (0.5.0): разрыв журнала обнаруживается при чтении.** Журнал — цепочка конвертов: конверт, записанный после другого, несёт `prev_id` — id предыдущего конверта того же файла; первый конверт файла цепочку не несёт. `prev_id` в схеме необязателен: пролитая кровь без цепочки (v0.4.0 и старше) валидна навсегда (п.6). Цепочка заявлена с первого конверта, несущего `prev_id`; каждый конверт после него обязан нести `prev_id`, равный фактическому предыдущему id файла, иначе — разрыв. `blood.journal.verify` при чтении отчитывается гэпами (строка, id, причина); повторная сессия того же дня продолжает цепочку с последнего конверта файла; битая строка и конверт без id якорем цепочки не служат. Гематология красит файл с гэпами.
8. **Реконструкция сессии (0.5.0): сессия ствола мозга полностью реконструируется по журналу.** `Journal.from_jsonl` читает файл в память (валидные конверты — в журнал, битые строки — честный счётчик `skipped`); `blood.resume.reconstruct(path, trace_id)` восстанавливает сессию по крови: план (намерения из `plan`), вызовы (`act` с ценой), наблюдения (`observe`), вердикты (`reflect`), остановки (`halt`) и полную цену трейса. Флаг `complete` — трейс закрыт по-записанному: последний конверт — `halt` либо удовлетворённая `reflect`, и гэпов цепочки в трейсе нет. Кровь — истина: реконструкция не достраивает того, чего в крови нет.
9. **Идемпотентность (0.6.0, волны №15–№16, A01): повторная доставка не повторяет эффект.** Конверт может нести `idempotency_key` (схема: строка 1–256; поле необязательно). Журнал помнит эффекты: повторный append того же `id` с тем же содержанием или того же `idempotency_key` возвращает уже записанный конверт — строка в кровь не пишется, цена и цепочка не дублируются; повтор ключа с другим payload — тоже дедуп (ключ называет намерение отправителя, записанное не подменяется), а тот же `id` с другим содержанием — не dedupe, а **конфликт: fail-closed (`EnvelopeError`)**. Скоуп памяти — журнал (файл); память восстанавливается при `attach()` и `from_jsonl()` — повтор ключа через смерть процесса не создаёт второе событие. Конверт без ключа и с новым `id` живёт как прежде — пролитая кровь v0.4/v0.5 валидна навсегда (п.6). Приёмки: `tests/test_blood_dedupe.py`, `tests/test_blood_dedupe_edges.py`.
10. **Честное происхождение конверта (0.7.0, W-0022, Ф-1.1 ТЗ ревизии): «событие без происхождения недостоверно».** Конверт может нести (все поля необязательны — схема аддитивна, кровь v0.4/v0.5 валидна навсегда, п.6):

   - **тройное время**: `occurred_at` — когда случилось в мире (string|null; null или отсутствие = UNKNOWN — честное незнание, не выдумка и не ноль); `observed_at` — когда тело увидело; `stored_at` — когда записано. `stored_at` ставит сам журнал при append — момент записи знает журнал, изготовитель конверта его не выдумывает; для конвертов старого контура ts = момент записи. Хронология честной записи: occurred_at ≤ observed_at ≤ stored_at (где оба известны);
   - **причинность**: `causation_id` (uuid) — id семантического родителя события: ответ на вопрос «какое событие стало причиной этого», не файловая цепочка `prev_id` (та шьёт файл, не смысл);
   - **класс доверия** `trust`: `unverified` (весть от чужих, самоотчёт), `verified` (тело видело само), `derived` (выведено из крови), `unknown` (не заявлено; отсутствие поля = unknown);
   - **класс приватности** `privacy`: `public` / `internal` / `personal` / `sensitive`; отсутствие поля = не классифицировано — любой контур наружу (донорство, публикация) обязан считать неклассифицированное = `sensitive` (fail-closed наружу).

   Неизвестный класс — fail-closed при записи (EnvelopeError), как неизвестный тип события (ADR-0014). **Транслятор пакет «Human Membrane» ↔ дом** (чужой словарь переводится, не копируется — ADR-0013): поле `retention` пакета отвергнуто (противоречит п.6 — пролитая кровь валидна навсегда); `correlation_id` пакета ≡ наш `trace_id` (жив во всей крови); `sequence` пакета ≡ файловый порядок + цепочка `prev_id`; `schema_version` пакета ≡ версия схемного файла `envelope.schema.json` — в конверт не дублируется. Различение estimated/actual цены — вместе с процессными оценками (W-0020, кандидат Ф-2.7).

11. **Адаптер чужого контракта и конвенции чтения (0.8.0, такт 2 волны №17): перевод зерна, не копия.** `blood/adapter.py` — тонкий слой перевода контракта пакета «Human Membrane» (решение Этапа 0): `event_name`→`type` — словарь из самой схемы (копии в коде нет — дрейф невозможен); `occurred_at` пакета переносится, null/absent — честный UNKNOWN (A02); заявленные `trust`/`privacy` переносятся, незаявленные не выдумываются; домовое `observed_at` — заявка адаптера о моменте приёма (их наблюдение — провенанс, не наблюдение дома), хронология честной записи видна в крови: occurred_at (факт у коллеги) ≤ observed_at (приём) ≤ stored_at (запись); их `causation_id` (строка произвольной формы) — провенанс в `payload["membrane"]`, домовое поле требует uuid; их `stored_at`/`sequence`/`event_id`/`schema_version`/`correlation_id`/`cost` — провенанс (момент записи знает наш журнал — п.10, порядок — append-only файл и `prev_id` — пп.4, 7, корреляция ≡ `trace_id`, цена приёма — параметр); неизвестный `event_name` — fail-closed (ADR-0014): error-конверт с оригиналом в payload — **сохранено, не исполнено (A17)**; `retention` не переносится (кровь валидна навсегда, п.6). **Конвенции чтения — `blood/provenance.py`** (`event_time`/`trust_of`/`privacy_of`): незаявленное не достраивается задним числом — доверие unknown, не классифицированное наружу sensitive (недоклассификация не может облегчить режим), время факта UNKNOWN. Приёмки: `tests/test_blood_provenance.py` (20).

## Типы событий (стартовый словарь)

`plan`, `act`, `observe`, `reflect`, `halt`, `veto`, `error`, `security.violation`, `organ.health`, `organ.replace`, `boot`, `shutdown`, `alert`

Тип `alert` (0.3.0) — предупредительное событие бюджета (SPEC-0001 G3): порог лимита достигнут либо
лимит одного вызова превышен (вызов уже оплачен — алерт, не запрет). Эмитент — ствол мозга;
payload содержит машину-читаемую причину (лимит, порог, имя показателя).

Честный отказ — данные, а не стыд (W-0021, волна №16): счётчик провалов `blood/refusals.py`
считает `veto`/`halt`/`error`/`security.violation` живой крови — сказано «нет», остановились,
ошиблись, остановлено стражем; `plan`/`act`/`observe`/`reflect`/`boot`/`shutdown`/`organ.*`
в счёт не входят — счётчик считает провалы, а не размывает жанр.

## Отказные режимы

| Ситуация | Поведение |
|---|---|
| Событие не валидируется схемой | отбрасывается до записи + событие `error` |
| Неизвестный класс `trust`/`privacy` | fail-closed при записи (EnvelopeError, ADR-0014) — до крови не доходит |
| Разрыв журнала | обнаруживается при чтении (п.7): `verify` отчитывается гэпами, гематология красит файл |
| Журнал недоступен | SPEC-0001: без крови действий нет |
