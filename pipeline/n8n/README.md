# Конвейер: n8n как внешний узел (SPEC-0007, ADR-0009)

n8n (fair-code, Sustainable Use License) — **внешний узел** организма COMMONS:
он не встраивается в тело, не попадает в зависимости и не вендорится
(SPEC-0006, SPEC-0007, ADR-0009). Конвейер — это **данные**:
референс-развёртывание `docker-compose.yml` и экспортированные воркфлоу
`workflows/*.json`. Валидатор `pipeline/check.py` (`python3 -m pipeline`)
проверяет их как код на каждый PR: провал — ненулевой код возврата, красный PR
(G1 fail-closed).

## Развёртывание (человек = PID 1, SPEC-0004)

```bash
cd pipeline/n8n
docker compose up -d
# открыть http://localhost:5678
# UI: Workflows → Import from File → импортировать JSON из workflows/
```

n8n поднимается человеком на своём хосте; секреты (ключи, переменные
окружения, юнит-файлы) в репозиторий не входят — в compose их нет.

## Воркфлоу

| Файл | Что делает | Точка входа |
|---|---|---|
| `workflows/commons-pulse.json` | каждые 30 минут — пульс организма через ствол мозга (SPEC-0001) | `commons-pid1 --max-beats 1` |
| `workflows/commons-immune.json` | раз в сутки — иммунный гейт по лицензионной матрице (SPEC-0006) | `commons-immune` |
| `workflows/commons-acceptance.json` | вручную — приёмки организма | `python3 -m pytest -q` |

Пульс идёт только через ствол мозга: конвейер не обходит кровь, бюджет и veto
и не вызывает органы напрямую (SPEC-0007, п. 3).

## Контракт белого списка команд

Каждый исполняющий узел (`executeCommand`) вызывает только точки входа
организма — пять записей `WHITELIST_COMMANDS` в `pipeline/check.py`:

1. `commons-pid1`
2. `commons-immune`
3. `python3 -m immune`
4. `python3 -m pipeline`
5. `python3 -m pytest`

Аргументы допустимы: нормализованная команда равна записи или начинается с
неё на границе токена. Shell-метасимволы — `;`, `|`, `&`, `` ` ``, `$(` — и
перевод строки запрещены; произвольный shell не проходит валидацию
(`command-not-allowed`). Новая точка входа — одна строка белого списка
(данные, G2), не новая логика.

## Иммунный барьер (SPEC-0006)

В реестре органов n8n закреплён как `fair-code (Sustainable Use)` +
`mode: external`, статус `not-embeddable`: барьер
(`immune/license-matrix.yaml`, `immune/barrier.py`) пропускает это сочетание
и запретил бы ту же лицензию во встраивание (`core_modes`). Конвейер ничего
не меняет в матрице — он её живая демонстрация: кода n8n в репозитории нет,
только декларативные артефакты, проверяемые валидатором.

## Границы

Живой запуск, секреты и наблюдение за n8n — на хосте человека (PID 1,
SPEC-0004): CI проверяет данные, а не живой n8n. Воркфлоу — снимок экспорта:
новая версия n8n может менять схему JSON (ADR-0009, последствия); валидатор
ловит структурные поля контракта, а не нюансы UI.
