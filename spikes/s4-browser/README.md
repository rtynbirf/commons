# Спайк S4: эффектор — browser-use end-to-end

Статус: приёмка готова к запуску, 20 сценариев (2026-11-01); живой прогон — на хосте
с браузером · Ограничение: ≤3 дня · Родитель: `docs/spikes.md` (S4) · Связь: ADR-0005

## Гипотеза

Браузер как эффектор подключается за стволом мозга по одному контракту инструментов
(`navigate`, `click`, `extract`, `screenshot`) и проходит типовые операции end-to-end
с записью цены в кровь — без специального кода в цикле (SPEC-0001 G2).

## Приёмка: 20 сценариев (scenarios.yaml)

Каждый сценарий: цель, шаги через контракт инструментов, критерий успеха, лимит секунд.
Прогоны: 5 на сценарий; успех ≥80% сценариев и ни одного выхода за полномочия
(`network: allowlist`, `fs: downloads-dir`) → эффектор получает вызовы в бою.

## Запуск (хост с браузером)

```bash
pip install browser-use   # или иной MCP-обёрнутый запуск браузера
python3 spikes/s4-browser/run.py --command "browser-use-mcp" --runs 5
```

Без `browser-use-mcp` на PATH харнесс печатает `NO_BROWSER` (код 2) — цифры не выдумываются.
Каждый шаг сценария — через `synapse/adapters/mcp_stdio.py:MCPStdioAdapter` (тот же класс
транспортов, что у markitdown): результаты могут пойти в кровь организма без нового кода.
