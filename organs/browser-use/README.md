# Орган: browser-use/browser-use

Система: эффекторы · Режим: dependency · Лицензия: MIT (верифицировано GitHub API 2026-11-01, перепроверено при подключении)
Статус: m1-адаптер готов — орган поднимается командой `browser-use-mcp` (MCP stdio); живой пульс — после приёмки S4 на хосте с браузером (ADR-0005)

## Роль в обмене

Эффектор-браузер: организм действует в вебе — навигация, клики, извлечение данных.
Приёмка спайка S4 (20 сценариев × 5 прогонов) определяет, когда он получает вызовы в бою.

## Контракт через синапсы

- Вход: `navigate`, `click`, `extract`, `screenshot` (адрес/селектор/цель).
- Выход: результат действия (`{"text": ..., "is_error": ...}`) — в конверт крови.
- Полномочия: `network: any`, `fs: {mode: read-write, paths: ["${DOWNLOADS_DIR}"]}` (v0.5.0) — работа органа и есть весь веб; запись файлов — только в каталог загрузок, и этот скоуп исполняется рантаймом (страж, SPEC-0002 п.8): незаданный `${DOWNLOADS_DIR}` — орган не развёрнут (п.6).
- Цена: секунды замером; токены — через метаболизм.

## Адаптер

`synapse/adapters/mcp_stdio.py:MCPStdioAdapter` — тот же универсальный MCP-клиент,
что и у markitdown: два органа одного класса транспортов, один код.

## Тест отключения

Замен в таблице нет. Отказной режим: `error` в крови → REFLECT → HALT задачи.
Скоуп fs (только каталог загрузок) ограничивает ущерб от подмены или падения органа — до v0.5.0 ярлыки `allowlist`/`downloads-dir` были декоративными, теперь исполнимы.
