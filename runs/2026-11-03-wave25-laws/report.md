# Волна №25 — законы при конфликте, гейт дрейфа аксиом, честный ADR транспорта

Дата: 2026-11-03 · Версия: 0.44.0 · Прогон: `run.py` · Кровь: `blood.jsonl` (10 конвертов, chained + hashed, опечатана якорем в `blood/anchors.jsonl`)

Служено «одно другое не исключает», три зерна одной волны:

1. **W-0036 — матрица приоритета законов** (дыра ревизии 2026-11-03 «нет приоритета при конфликте законах»): порядок назван заранее, по-записанному — ADR-0016 + данные [`docs/axioms.yaml`](../../docs/axioms.yaml) (`laws_priority`). Порядок: честность → безопасность → кровь → тождество → дисциплина → время. При равном законе — «одно другое не исключает» (обе линии служат, стык сшивает), монеты нет.
2. **W-0034 — гейт дрейфа аксиом**: живая матрица A01–A25 — данные с указателями доказательств и планами у открытых; доктор получил гейт `axioms` (724 → 760 проверок): чужой вердикт, мёртвый указатель, вердикт без доказательства, открытая без плана, неполная матрица, нечитаемый yaml — блохи, fail-closed.
3. **Ф-3.1 — честный ADR «только stdio»** (ADR-0017): HTTP+OAuth 2.1 не строится без живого сценария сетевого вызова тела; тело без каналов (SPEC-0010), `transport_default: stdio` — данными, приёмкой.

## Честные границы

- Матрица `laws_priority` — вердикт дома о порядке законов, не физическая константа: новый живой конфликт обязан быть вписан в ADR-0016 (правило вспышки), иначе решение — блоха того же класса, что хотёлка без статуса.
- Гейт `axioms` судит дрейф матрицы (формат, указатели, планы), а не истинность вердиктов — истинность держат приёмки и живая кровь; врать матрице не помогает ни один вердикт.
- ADR-0017 не запрещает транспорт навсегда: живой сценарий сетевого вызова обязан сначала попасть в SPEC-0002 (спека раньше кода), audience-binding вписывается аддендумом.
