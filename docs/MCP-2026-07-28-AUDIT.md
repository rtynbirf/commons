# MCP spec 2026-07-28 · аудит сессий в commons · Э-2.1 (#7)

Статус: это ПРОТОКОЛ аудита и карта миграции, а не результаты. Конкретные строки
кода (колонка «что сейчас») заполнятся прогоном сканера `tools/mcp_session_audit.py`
из п.2 — до первого живого диспатча здесь нет выдуманных находок.

## Метод аудита

1. Сканер идёт по каталогу `--root synapse/` (по умолчанию) и ищет паттерны
   держания состояния сессии: `Mcp-Session-Id`, `session_id`/`sessionId`,
   `initialize(`, `initialized`, глобальные dicts/синглтоны сессий
   (полный реестр регексов с пояснениями — в шапке сканера, S1..S6).
2. Находка печатается как `файл:строка:паттерн` с пояснением; вердикт:
   есть/нет зависимость от транспорт-сессий; находки → exit 1 (гейт).
3. Найденное переносится в таблицу ниже, миграция идёт по колонке «как переводим».

## Аудит-дифф (пункт spec → commons → миграция → приёмка)

| Пункт spec 2026-07-28 | Что в commons сейчас (synapse/) | Как переводим | Приёмка |
|---|---|---|---|
| Stateless core: этап `initialize`/`initialized` удалён | заполнит сканер (файл:строка) | убрать handshake-состояние; каждый запрос несёт всё нужное в себе | 0 находок S3/S4 |
| Заголовок `Mcp-Session-Id` удалён | заполнит сканер | вынуть идентичность из транспорта; она живёт в полезной нагрузке/артефактах | 0 находок S1 |
| Каждый запрос самодостаточен (`_meta`) | заполнит сканер | состояние сессии храним в артефактах (файлы/реестры), не в памяти процесса | 0 находок S5/S6 |
| Header-роутинг | заполнит сканер | маршрутизация по заголовкам запроса, не по session id | нет ветвлений по идентификатору сессии |
| Кэшируемые list-ответы | заполнит сканер | ключ кэша — только параметры запроса, без сессионной составляющей | list-ответы воспроизводимы без сессии |
| Formal deprecation policy 12 мес | окно миграции фиксируется в issue #7 | старое поведение живёт ≤ 12 мес с даты спецификации, потом отключается | отметка в PULSE/issue после миграции |

## Как запускать

- Selftest без сети: `python3 tools/mcp_session_audit.py --selftest` → печатает `SELFTEST OK`
  (временная выборка из 3 файлов через tempfile, проверка всех паттернов S1..S6).
- Живой скан: `python3 tools/mcp_session_audit.py --root synapse/` → находки +
  вердикт; exit 1, если зависимость от транспорт-сессий есть.
- CI: `.github/workflows/mcp-session-audit.yml` — среда 06:00 UTC + `workflow_dispatch`,
  дом `wave5-mcp-audit`, сводка в `$GITHUB_STEP_SUMMARY`, гейт честный.
