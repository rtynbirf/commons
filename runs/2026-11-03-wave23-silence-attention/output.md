## Политика внимания на живых решениях (W-0025)

- `P0` safe_default=false → СПРАШИВАЕМ: P0: остановка перед риском/необратимостью — спрашивает всегда — безопасного default у риска нет
- `P0` safe_default=true → СПРАШИВАЕМ: P0: остановка перед риском/необратимостью — спрашивает всегда — безопасного default у риска нет
- `P1` safe_default=false → СПРАШИВАЕМ: P1: срочное существенное решение — спрашивает без безопасного default — безопасного default нет
- `P1` safe_default=true → не спрашиваем: P1: есть безопасный default, который можно изменить позже — косметический вопрос не задаётся
- `P2` safe_default=false → не спрашиваем: P2: дневная сводка — не прерывает — прерывания нет
- `P3` safe_default=false → не спрашиваем: P3: тихая запись — не прерывает — прерывания нет

## Итог правила тишины (W-0032)

- вопрос без окна не существует (fail-closed, ADR-0014);
- одобрение до окна — granted, с честной причинной связью на запрос;
- тишина за окном — veto от правила (по умолчанию «нет»), повтор — та же строка (A01);
- опоздавшее одобрение — весть в крови, необратимое не оживляет;
- ожидание не остановило дом: трейсы 1–5 идут один за другим.
