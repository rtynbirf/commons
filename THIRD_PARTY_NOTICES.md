# Сторонние компоненты (органы)

COMMONS **не копирует** код органов: органы остаются в своих upstream-репозиториях, здесь живут только спеки, адаптеры и реестры. Ниже — атрибуция и предварительные лицензии на 2026-11-01.

Перед фактическим подключением лицензия перепроверяется по файлу `LICENSE` в репозитории органа на дату подключения (закон иммунитета, ADR-0001). Пометка «предварительно» означает: значение сверено по памяти об открытом коде, требует подтверждения по файлу LICENSE.
