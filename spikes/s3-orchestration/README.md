# Спайк S3: оркестрация — n8n против Dify против langflow

Статус: лицензии верифицированы живым API 2026-11-01; сценарий и вердикт — на живой машине ·
Ограничение: ≤3 дня · Родитель: `docs/spikes.md` (S3) · Связь: ADR-0002, PROVENANCE §5

## Гипотеза

Визуальные платформы дублируют синапсы (свой манифест узлов, свой лог, свой протокол), а не
заменяют их. Организм COMMONS держит нервную систему у себя; платформы допустимы как
внешние узлы обмена — по режиму из `organs/registry.yaml`.

## Метод

Один конвейер «документ → Markdown → краткая фраза» (аналог пульса
`runs/2026-11-01-organism-pulse/`) собирается на каждой платформе:

1. **время сборки** — минуты от пустого канваса до рабочего конвейера;
2. **что видит кровь** — какие события и цены платформа отдаёт наружу (webhook/лог), может ли
   трейс платформы реконструировать сессию с ценами (SPEC-0003);
3. **режим лицензии** — встраивание/внешний узел по верифицированной матрице;
4. **заменяемость** — как быстро конвейер переезжает на другой орган (ollama ↔ llama.cpp).

## Лицензии (GitHub API `GET /repos/{owner}/{repo}/license`, 2026-11-01)

| Платформа | SPDX по API | Файл | Режим в теле |
|---|---|---|---|
| langchain-ai/langchain | MIT | `LICENSE` | `dependency` — орган, не ствол мозга (см. спайк S2) |
| langflow-ai/langflow | MIT | `LICENSE` | `reference` — изучение |
| langgenius/dify | NOASSERTION | `LICENSE` | Apache-2.0 с доп. условиями → `adapter`, условная лицензия |
| n8n-io/n8n | NOASSERTION | `LICENSE.md` | fair-code (Sustainable Use) → `external`, не встраивается |

Расшифровка NOASSERTION — в `PROVENANCE.md` §3: это «GitHub не распознал автоматически»,
не «нет лицензии».
