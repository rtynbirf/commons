# ADR-0020: REUSE — канон лицензирования аккаунта; CycloneDX SBOM на каждый релиз

Статус: принято · Дата: 2026-11-09

## Контекст

commons — основание дома и единственный репо аккаунта с REUSE.toml
(мембранный аудит 2026-11-08 §III-11: 40/41 репозиториев без SPDX-мембраны;
«решение о стандарте за домом» не было принято). Лицензионный вопрос аккаунта
уже решён по существу — Apache-2.0 на всё (ADR-0003), REUSE-линт исполняется
в CI commons — но канон не был назван каноном, и машинный слой провенанса
поставок (SBOM) отсутствовал.

Мировая практика 2026-11 (срез волны FIX-1.3): SPDX/REUSE — стандарт
поофайльного лицензирования; CycloneDX/SBOM + SLSA-провенанс — стандарт
поставок (scorecard.dev, SLSA). ПРЕДЛОЖЕНИЕ-38 (issue #12) предлагало
обе половины; настоящим ADR дом решение фиксирует.

## Решение

1. **REUSE 3.3 — канон лицензирования аккаунта.** Эталон — commons:
   `REUSE.toml` + job `reuse` (fsfe/reuse-action) в CI. Тираж SPDX-заголовков
   в остальные репозитории аккаунта — храповиком (ratchet): только-добавление,
   после тяжёлых пунктов, приоритет P3; каждый репо получает REUSE.toml +
   линт без переписывания истории.
2. **CycloneDX SBOM на каждый релиз commons.** Воркфлоу `release-sbom.yml`:
   на `release: published` генератор `scripts/sbom_cyclonedx.py` строит
   `sbom.json` и прикладывает его к релизу (append-only, без clobber).
   Генератор — только stdlib, детерминированный: без часов (timestamp
   опущен либо задан явно), serialNumber = UUIDv5 от коммита, компоненты —
   отсортированные файлы `git ls-files` c sha256 живых байтов. На каждый
   пуш — selftest (`scripts/sbom_selftest.py`): двойная сборка байт-идентична,
   структура валидна, множество компонентов == `git ls-files`, хеши сверены.
3. **SBOM — машинная приёмка релиза:** последний релиз commons содержит
   `sbom.json`, валидный схемой CycloneDX 1.5.

## Последствия

- Релиз без sbom.json = красный воркфлоу (fail-closed), а не надежда на память.
- Детерминизм SBOM делает его допускаемым в пломбы и SHA256SUMS: одинаковый
  ввод (дерево коммита) — одинаковый вывод (байт-в-байт), проверяемо двойной
  сборкой в любом окружении.
- Храповик SPDX по аккаунту не трогает чужие волны: шаг тиража — отдельная
  волна, эталон и приёмки живут здесь (commons), чтобы копия была честной.
- Лицензионный барьер тела (SPEC-0006, ADR-0008) остаётся без изменений:
  SBOM описывает поставку, барьер охраняет вход.
