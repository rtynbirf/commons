# Отчёт волны №19 — Ф-1: выжимка крови, недельный агрегат (W-0019)

Дата: 2026-11-03 · База: `a927f78` (0.37.0) · Директива Человека: «ПРОДОЛЖИ С
МЕСТА ОСТАНОВКИ» — следующая ступень фазы Мембраны после дневника (W-0023,
волна №18): W-0019 — агрегатный слой того же зерна.

## Что служено

**SPEC-0003 v0.10.0 п.13** — `blood/digest.py`: дом сам выжимает смысл из
своей крови — что **понял**, что **болело**, что **закрыл**, чем **пахнет** —
текстом для Человека, без чтения 30+ jsonl глазами. Дневник (п.12) —
по-действенный слой, выжимка — агрегатный слой; обе проекции только читают,
кровь не переписывают, ничего не забывают.

Честные правила агрегата:

- **окно недели — по моменту записи** (`ts`): момент факта может быть старше
  (п.10) — события вне окна названы счётчиком, не спрятаны («не забыты»);
- **болело** — счётчик провалов W-0021 (veto/halt/error/security.violation),
  алерты бюджета, повреждения файлов (гэпы `prev_id`, битые строки);
- **закрыл** — трейс закрыт, если последний его конверт `halt`/`reflect`;
  открытые трейсы названы (счёт + примеры), не приукрашены;
- **пахнет** — только измеримое: доля незаявленного времени факта (A02),
  незаявленного доверия, неклассифицированной приватности, планы без
  причинно-связанного исполнения, максимальная задержка наблюдения
  (факт → запись);
- цена недели: токены/секунды по окну + самые дорогие органы по секундам.

## Границы (названы честно)

- Выжимка не выбирает «интересное» и не интерпретирует запахи — только
  измеримые сигналы; интерпретация — за Человеком и Ф-2 (conscience).
- Окно фиксировано 7 дней (WINDOW_DAYS) — параметр, не политика;
  еженедельный запуск по расписанию — дело CI (кандидат, не заявляем).
- «Планов без исполнения: 107» — честный сигнал всего дома: красные прогоны,
  сцены-атаки и аудиты живут в той же крови; сепарация жанров — W-0019+,
  не выдумана.
