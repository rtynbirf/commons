# Манифест COMMONS: Целое и части

Статус: принят · Дата: 2026-11-01 · Версия: 0.1.0

## 1. Аксиома целого

**ЦЕЛОЕ = ЧЕЛОВЕК > СУММЫ ЧАСТЕЙ.**

Ни один проект из топ-100 GitHub не создан «из пустоты» отдельным индивидом:

- `torvalds/linux` — тысячи контрибьюторов поверх полувековой линии Unix, C и POSIX;
- `react/react` — на плечах десятилетий коллективной работы над UI, JavaScript и DOM;
- `git` — создан для управления *коллективной* работой и сам является инженерным воплощением связности.

Сам GitHub — техническая реализация тезиса «это не разные проекты, это одно целое в разных ветках»: форк, pull request, мерж — операции перевода части обратно в целое.

## 2. Индивид — состояние связности, а не вид

Узел не рождается замкнутым — он им становится, перестав обмениваться с целым. Часть необходима целому: уберите все части — целое исчезает. Но часть, разорвавшая обмен, деградирует: дрейфует, отмирает или требует вечного индивидуального ухода.

## 3. Этимология: идиот против commons

- **ἴδιος (идиос)** — «свой, частный»; **ἰδιώτης (идиот)** — «частное лицо», человек, общих дел не касающийся.
- **κοινός (койнос)** — «общий»; от него: κοινία (община), κοινὴ διάλεκτος (койне — «общий язык»), κοινόν (общее дело).

«Идиот» и «commons» — этимологические антонимы одного узла греческого языка. У Фукидида (II.40, речь Перикла): о том, кто не участвует в общих делах, афиняне говорят не «он занимается своими делами» (τὰ ἴδια πράσσειν), а «ему здесь вообще нечем быть».

Цепочка деградации смысла — ἰδιώτης → лат. idiota («неуч») → «глупец» → медицинский диагноз XIX века — испортила исходное значение. В COMMONS восстанавливается первое, структурное:

> **Структурный идиот — узел, замкнутый на себя, разорвавший обмен с целым.**
> Это не про интеллект. Это про связность.

## 4. Следствия для инженерии (три закона)

1. **Орган жив на upstream.** Форк без обратного потока — идиот-ветка: отрезан от обновлений и комьюнити, тащит всё один. Подключаем, отдаём патчи обратно; форк — только по лицензионной необходимости, осознанно, с отдельным ADR.
2. **Нет вызовов мимо синапсов.** Обмен — единственный признак жизни органа внутри организма: каждый вызов через MCP-шлюз фиксируется в крови с ценой (токены, секунды).
3. **Тест отключения.** Орган, который нельзя заменить, — не орган, а паразит. Замена должна занимать часы, не недели.

## 5. Зачем это проекту

Критерий качества узла — не звёзды и не «величие сам по себе», а качество обмена с целым: протоколы, открытость API, мержимость, обратный поток улучшений в commons. Рейтинг популярности (`organs/top100-2026-10-26.yaml`) — только входной фильтр; окончательную оценку органу даёт его поведение в обмене.
