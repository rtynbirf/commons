1. Пакет не внедрять «слоем»: тонкие адаптеры, дублирования нет — никаких новых

3. Append-only: версии, кровь, реестры — только вперёд; force-push запрещён;
   каждый коммит DCO.
4. Гипотезы пакета (80/15/5, торможение 85%) — не факты: спайк → замер → ADR.
5. Критерии готовности не менять задним числом; каждый пункт — волна или такт,
   не «свалка».
6. Уплотнение связей приостановлено до отдельного слова Человека.
